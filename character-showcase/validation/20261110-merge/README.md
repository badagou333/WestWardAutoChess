# D-20261110-005｜三个角色展示合并 作者回归证据

2026-11-10，06。基线 origin/main d19a97f。环境：Windows 11，Godot 4.7.2 stable（console 版），OpenGL3 Compatibility，AMD Radeon RX 7700 XT，专用 1440×810 窗口，Dummy 音频＋主总线静音。**作者自测，不代替 07 独立回归、05 实际视觉、真人观感或设备听感。**

## 方法：合并前后行为指纹对比

1. **合并前**：把 d19a97f 的三个旧项目原字节导出到临时目录（`git -c core.autocrlf=false archive`），在每个旧项目里运行 [exporters/legacy_baseline.gd](exporters/legacy_baseline.gd)，旧项目文件不改动，得到 `baseline/legacy-{bear,c03,b04}.json`。旧树清单见 `baseline/legacy-tree-d19a97f.txt`。
2. **合并后**：在新结构里经真实 app 场景（`main.tscn` → `open_character`）运行 `tests/baseline.gd`，输出同格式的 `merged-*.json`。
3. **对比**：用 `tools/compare_fingerprints.py` 逐项比较。除原生音频播放位置允许差 2 个采样（按 32 kHz 计）外，其余全部要求完全相同。结果在 `compare-*.json`。

指纹按“每个角色 × 每个方向”记录：

- **帧和纹理**：帧数；每帧源时间；每帧纹理像素的 SHA-256（药龄童子含 mipmap 数据）。
- **脚点**：画布四角和脚锚映射到世界坐标的结果（含镜像）。
- **时间轴**：以 1 毫秒为步长逐点查帧，熊山君查两个完整周期，其余查到 T 之后 0.2 秒。另在每帧起点及其前后 1e-7 秒、T、T+5 秒处取边界样本。
- **声音轨迹**：用固定的不规则步长序列推进，逐步记录 elapsed、当前帧、状态、是否在播、是否新起播，以及起播时的原生位置。熊山君推进 2.5 个周期，单次模式推进到结束后 0.3 秒。
- **切方向轨迹**：熊山君切方向会从头重启；翠鸟切向时间不变、声音实例不变。
- **实窗裁片**：1440×810 真实窗口截取 (520,200,400,360) 区域的 RGBA SHA-256。熊山君每方向 9 个时刻，翠鸟每向 9 帧（含真正 Ended 97），药龄童子 11 帧（含第 35 帧和 Ended 83）。

## 过程中的修正（保留说明）

- **导出器首版**：GDScript 类型推断报错，补上显式类型后重跑。旧版切方向轨迹在翠鸟声音起播前就读取了播放实例，会让“切向时声音实例不变”的结论失真；已改为起播后再读取，三个角色全部重新导出。最终的 legacy JSON 都来自修正后的导出器。
- **选择界面**：首版的锚点写法触发了 Godot 的尺寸告警。去掉锚点预设后重跑实窗启动和引擎检查，均无告警。
- **体积**：合并后的裁片与旧裁片散列完全相同，所以只保留旧裁片（`baseline/legacy-crops/`，65 张）。
