## 验证

`godot --headless --path godot-demo --script res://tests/recruit_ui_test.gd`：五图片、名称、控件矩形边界/不重叠、八格点击映射、购买及售出清图、免费刷新、升级人口、拖放上阵/返回最后候选格、满席禁购、战斗禁用、重开清空均通过。测试通过程序发出购买信号及调用拖放处理，非逐项人工鼠标验收。

实际 OpenGL 窗口运行同一检查，以 `RECRUIT_UI_PREVIEW` 指定保存位置，输出 `recruit-ui-preview-empty.png`（空席）和 `recruit-ui-preview.png`（八格占用演示）。两图1440×810复核：图片可见、无底栏控件遮挡，队员与星级位于候选区。满席图的商店变暗属于禁购提示。

冒烟、棋盘几何及综合多帧率/倍速战斗零失败，综合结果保持约64.98秒、唐僧290/300、金币25，事件219攻击/46投射/172伤害/46治疗/1取消。启动时沙盒日志/证书告警不影响无界面检查；实际窗口另经权限运行成功，早先阻塞实例已关闭。

不宣称所有屏幕比例和输入设备已验收；沿用现有1920×1080逻辑画布与窗口缩放。无改战斗规则、音效或棋盘校准，无新定时运行。
