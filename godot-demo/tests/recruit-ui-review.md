## 后续修订：折叠商店与实体替补格（当前）

商店默认隐藏，空格或左下按钮展开/收起，Esc及面板右上关闭按钮收起；按住空格不连切。数字1—5购买和R刷新仅在商店展开时有效，E升级人口保留。空格不再开战/暂停，开战用原按钮，暂停用P或原按钮。战斗可展开查看商店但仍禁止购买/刷新；展开不自动暂停。开战、结算和重开都收起商店。

底部替补席始终可见，八个原生绘制石台具有顶面、前沿、厚度和投影，人物仍为独立Node2D站在格面上；空/占用颜色、数量、星级和拖放保留。未新增待机动画，后续可在角色播放器扩展而无需改格台结构。人口升级保持右下独立按钮。

新增bench_tile.gd，修改game.gd，扩展recruit_ui_test.gd。截图更新为默认空席、收起商店满席、展开商店满席（recruit-ui-preview-open.png）。1440×810实际OpenGL截图已复核。新增测试覆盖默认隐藏、隐藏时无盲购/刷新、空格切换/长按、按钮、Esc、战斗不因空格暂停、重开收起；面板设置阻断鼠标穿透（属性检查，不宣称逐像素人工点击验收）。专项、冒烟、棋盘35格与综合多帧率/倍速战斗均零失败，战斗结果与下方基线一致。

下方为首轮实现记录，常驻商店/右侧双按钮布局已被本修订替代。

- 五张招募卡：复用各角色 demo_v1 的待机图片，自适应透明主体边界；名字、金币、数字键常显，定位与品质可悬停查看。兼容旧新两种 manifest。
- 八格待上场区：与商店分区，清楚编号、空位边框、占用金边及已用数量；修复原槽位底框被 UI 底栏覆盖。候选角色放大至 .62，棋盘比例不变。
- 免费/付费刷新和人口升级：右侧上下独立按钮，不压候选席或彼此。状态/金币/满候选席禁用逻辑保持。

## 验证

`godot --headless --path godot-demo --script res://tests/recruit_ui_test.gd`：五图片、名称、控件矩形边界/不重叠、八格点击映射、购买及售出清图、免费刷新、升级人口、拖放上阵/返回最后候选格、满席禁购、战斗禁用、重开清空均通过。测试通过程序发出购买信号及调用拖放处理，非逐项人工鼠标验收。

实际 OpenGL 窗口运行同一检查，以 `RECRUIT_UI_PREVIEW` 指定保存位置，输出 `recruit-ui-preview-empty.png`（空席）和 `recruit-ui-preview.png`（八格占用演示）。两图1440×810复核：图片可见、无底栏控件遮挡，队员与星级位于候选区。满席图的商店变暗属于禁购提示。

冒烟、棋盘几何及综合多帧率/倍速战斗零失败，综合结果保持约64.98秒、唐僧290/300、金币25，事件219攻击/46投射/172伤害/46治疗/1取消。启动时沙盒日志/证书告警不影响无界面检查；实际窗口另经权限运行成功，早先阻塞实例已关闭。

不宣称所有屏幕比例和输入设备已验收；沿用现有1920×1080逻辑画布与窗口缩放。无改战斗规则、音效或棋盘校准，无新定时运行。
