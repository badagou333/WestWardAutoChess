仓库根运行：

```sh
python3 scripts/verify_board_audio.py --mode noncommercial
python3 scripts/verify_board_audio.py --mode commercial
```

第一条应核对源→运行8个文件的固定哈希、44.1kHz/16-bit PCM/声道/帧数、9事件映射、狐火A、完整署名及猎户精确例外；第二条应明确拒绝所包含的猎户NC，返回非零。默认未传 `--mode` 也按commercial安全拒绝。

清单的 `sha256` 是含文件头的完整WAV哈希，用于源→运行逐字节复制核对；`pcm_sha256` 是 `wave.readframes` 返回的交错小端16-bit PCM字节哈希。Godot导入后通常包内为 `.wav.import` / `.sample`，不代表原始WAV文件头仍可读取；后续运行→PCK应以加载后 `AudioStreamWAV.data` 对比PCM哈希，再核44.1kHz、16-bit、声道、帧数。不能拿PCM哈希冒充原文件哈希，也不能仅有导入条目便声称包内音频相同。

验证器不会运行或播放游戏、不会联网，也不声称实际事件触发、暂停/静音/倍速/死亡/重试、真人听感或最终PCK已通过。06/07仍须分别完成这些验收及运行→PCK核对。
