## 来源与再制作

- 全部声音由本包 `tools/generate.py` 原创程序合成；固定随机种子，使用噪声滤波、非谐波共振、音高包络及谐波合成。无外部采样、购买素材、第三方音源或真人声线模仿。
- 制作工具：Python 3、NumPy；二者用于运算，未复制其音频素材。当前环境 NumPy 1.26.4。运行 `python3 tools/generate.py` 可在本包内重建音频、清单和试听页。
- 来源记录为“项目内自制程序合成”，没有外部素材署名义务；本记录不擅自为整个项目新增公开授权许可证。正式发布前随项目统一确定资产授权说明。
- 本批是质感验证小样。未接入专门的拟真生成服务；若合成兽声或武器声不符合听感预期，下一批可替换为经授权的录音或音效素材。

## 交付与程序接入建议（待实机验证）

由06接入，08不修改运行时代码。格式：44.1 kHz、单声道、16-bit PCM WAV，无循环、无刻意前置静音。保持现有总音量0.35作为首次试接起点，不能依据文件峰值直接断言设备端足够响。

- 近战攻击声在**实际命中结算**播放；远程山雀与狐火在投射物释放播放，目标命中可使用共用受击声；治疗在实际治疗生效时播放。不要同时叠加现有通用 release/hit/heal 占位声。
- 受击按目标材质选择一个：肉身/毛皮/护甲。护甲角色建议护甲，其余按实际外观选择；不从角色种族推导新玩法。近战攻击本身已含冲击，试接时可降低附加受击声或省略，避免双重敲击。
- 致命命中只播放一次退场/死亡，抑制该次普通受击；攻击方的命中声可保留。出售、撤下棋盘、场景卸载不得触发战斗退场。
- 初始混音：攻击峰值约-14至-8 dBFS，共用受击-18 dBFS；英雄退场-11至-10 dBFS，小怪死亡-15至-13 dBFS，Boss死亡-7 dBFS，唐僧警示-8 dBFS。峰值不是响度指标，RMS也不能替代试听；不逐条拉至0 dBFS。
- 建议优先级：唐僧警示/Boss死亡 > 英雄退场 > 关键攻击/治疗 > 小怪死亡 > 普通受击。沿用8路起步；满路时允许高优先级替换低优先级，不能让唐僧警示被普通攻击全部占用。最终声音总线建议留余量并加限幅保护，需06实现和实测。
- 建议冷却：同事件键攻击60毫秒；共用受击120毫秒、同一目标受击180毫秒；同种小怪死亡200毫秒；唐僧警示1秒。不同英雄退场不互相吞掉；以上全为试接参数。
- 暂停时停止推进战斗音频，恢复后继续；重开/退出停止所有旧声音。2倍速只增加事件频率，不将音高翻倍，冷却按现实时间计，具体密度在实机调整。
- 为减少首批范围，每事件先交一个版本；重复疲劳明显后再制作2～3个真实变体，不以随机变调取代全部差异。

## 验收边界

已做文件技术检查：22条事件唯一、PCM格式、帧数、非空有效信号、首尾零点、峰值余量、文件校验、试听页引用、生成复现性。没有进行人工听感验收、正常窗口输出设备核查或游戏内混战验证；不得把这些技术检查写成“已经听见”或“音效验收通过”。

试听顺序：先逐条判断角色辨识与刺耳感，再比较攻击/受击/退场音量，最后试接1×/2×密集战斗，检查命中同步、警示是否被遮盖、暂停恢复和重复触发。未通过者保留待审，不替换正式资产。音乐、语音及招募/合成/胜败专属升级不在本批范围。
