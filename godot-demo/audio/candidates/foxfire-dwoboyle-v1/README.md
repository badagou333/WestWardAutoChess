## 试听

打开 `index.html` 可对照原素材公开预览与两种修改。

- **A 保留原声版：0.57秒。** 保留原声有效部分，去除约0.3秒接近静音的尾段、转单声道、短淡入淡出和峰值对齐。不添加音色层。
- **B 短促发射版：约0.455秒（优先试听）。** 保留原声主要发射和火焰质感，裁去35毫秒前段、收紧尾音、轻微滤除低频轰鸣并削弱高频尖锐区域，适合尝试频繁普攻。没有变调、整体加速或添加合成声音。

两版均44.1kHz、16-bit PCM、单声道、峰值约-11dBFS。优先B是制作建议，并非人工听感结论；以负责人试听为准。

## 来源质量与复现

本次使用页面公开HQ MP3预览（原始WAV下载需要登录），保留原下载和解码文件供复现。页面原声音长0.877秒；信号检查显示后段约0.3秒接近静音。两声道相关系数约0.99999986，混为单声道不会产生明显相位抵消。

解码命令（macOS）：

```sh
afconvert -f WAVE -d LEI16@44100 -c 2 source/136696_2289019-hq.mp3 source/preview-decoded.wav
python3 tools/adapt.py
```

生成工具使用NumPy；具体滤波、切点、包络与校验值见源码和manifest。保留了MP3压缩来源的限制，不能将增加WAV位深称作提升原素材质量。若后续取得原始WAV，可沿用该编辑方向重新制作。
