# 西游护送 · 行路试炼

2026-09-30 起默认进入 `scenes/escort_route.tscn`：不规则离散格子地图，唐僧沿金线从 A 到 B，玩家实时调动队员拦截沿途敌人。复用既有商店、合成、人口、角色、动作和音效；旧固定棋盘 `scenes/main.tscn` 保留作回归及对照。

当前为四段护送＋营地经营的玩法原型。地图采用程序绘制的简化地形，不是最终美术；灰鼠和唐僧仍保留旧素材。章节进度、自动存档和完整技能尚未完成。

## 启动

需要 Godot 4.7.2 Standard（Compatibility 渲染）。

- Mac：双击本目录 `launch.command`，或运行 `bash godot-demo/launch.command`。
- Windows：双击本目录 `launch.cmd`。可将 `GODOT_BIN` 设为 Godot 可执行文件完整路径。
- 命令行：仓库根目录执行 `godot --path godot-demo`。
- 编辑器：导入本目录 `project.godot` 后运行主场景。

首次运行由 Godot 导入现有资源；启动器需要本机安装引擎，当前不是免安装发布包。

免安装的 Windows x86_64 试玩包使用仓库根目录的发布脚本生成：

```sh
./scripts/build_windows_release.sh 0.2.0-playtest.1
```

构建要求 Godot 4.7.2 与匹配的 Windows Release 导出模板，产物默认写入仓库外发目录 `build/windows/`（已忽略，不提交 Git）。完整发布与 Windows 实机验收步骤见 [`docs/release/WINDOWS_PLAYTEST.md`](../docs/release/WINDOWS_PLAYTEST.md)。

## 首次体验

1. 初始3金币、3人口；空格展开商店，首轮展示五名不同的一费英雄，后续刷新允许重复。
2. 新模式建议先购买护寺棍僧、山雀精和药灵童子；不要只留近战在原地等待。
3. 将队员部署到唐僧附近的绿色地块，避免挡住金线路径，再点击“出发”。红框表示本段入口，闪红格表示下一只敌人的位置。
4. 战中左键选人再点空地，或将队员拖向目标格、右键指定目标。下令后逐格行走，不瞬移、不交换占位；到位驻守、射程内自动攻击/治疗，不会自动全场追敌。把前排送到来敌方向，远程和治疗随唐僧推进。
5. 唐僧抵达营地且清敌后进入不限时整备：战利品入账、商店补满、一次免费刷新；可以继续招募、三合一、出售或升人口。英雄恢复但保持行进后站位，阵亡英雄复归空格；唐僧保留血量。手动出发下一段，最终到 B 并清敌获胜。
6. 结算后“重新体验”会重置路线、金币、阵容和商店。当前不保存进度。

可另行尝试山雀精的远程投射、狐火小妖的小范围伤害。前排、近战输出、远程、治疗、范围输出的基础行为已接通；护盾、猎犬、山雀增益、熊山君完整技能和二三星新增技能仍待后续实现。升星当前增加基础属性，技能说明会显示尚未实现的内容。

## 操作与规则

- 点击商店或按数字键1—5购买；拖动角色，或先选角色再点击格子布阵。
- 唐僧所在格、水面和地图外不可部署；整备只能新部署到唐僧周围3格陆地，战中可走遍连通陆地。候选区8格，上场人数受人口限制。
- R刷新：每轮整备一次免费（不累积），之后2金币；E升级人口，升4人口4金，后续6/8/10/12/14/16金。
- 三名同身份、同星、未锁定英雄自动合成，最高三星；点击角色可以出售或设置合成锁。
- Space或左下按钮展开/收起招募商店，默认收起；Esc或面板关闭按钮收起。数字购买/R刷新仅在商店展开时生效。底部八格石台替补席常显，拖动队员上阵。
- 开战使用“出发”按钮；P或右上按钮暂停/继续。暂停冻结移动、动作、飞弹、治疗和波次，但允许下达移动令，恢复后执行。Esc取消选中队员的移动令并取消选择；收起商店的功能保留。
- 唐僧沿金线前进；右侧“暂驻/继续行进”只控制唐僧，不暂停战斗。敌人贴身或下一格被占时等待，需要回防或让路。移动中起点与终点均保留占用，避免穿人；敌人入口被占会等待腾空，不刷在角色身上。
- 普通攻击在动作释放时命中；飞弹和治疗在抵达时结算，每次只结算一次。
- 唐僧死亡失败；每波成功时按当时血量发放80%/90%/100%战利品（向上取整），立即用于下一波。满血各波可得3/4/6/7金；最终只发最后一波，不重复发之前奖励，并按最终血量评星。
- 失败不发当前波战利品，之前已发金币不回扣；本轮终止，重新挑战从3金币与空阵容开始。章节失败回退和存档尚未接入。
- 四波敌人组合不变，入口改为沿路线分布；生命系数1.0/1.15/1.35/1.60，伤害系数1.0/1.05/1.10/1.20，给营地招募/合成留出成长空间；均为试玩参数。
- 音效使用已采用的角色音效及少量UI占位音，支持关闭和调音量；包含第三方狐火改编素材，署名见CREDITS.md；没有加入震屏。

## 自动检查

新模式专项：`godot --headless --path godot-demo --script res://tests/escort_route_test.gd`。
覆盖地图连通与点选映射、战中指令/无瞬移、暂停与双端占位、唐僧让路/暂驻、入口等待、封路敌人逼近守军、移出近战射程、营地合成/升人口、胜败/重开和不同帧率倍速。

固定测试购买与指令策略（不是 AI 队友功能）：首营地购买两名棍僧合为二星，第二营地升人口并补狐火。约108.4模拟秒抵达B，唐僧297.6/300，战利品20；30/60 FPS及120 FPS×2的最终血量/收益一致。相同初阵、相同营地购买策略但不给移动令，约39.1秒在第二段失败。此对照证明调度有实际作用，不代表难度已平衡，也不代表商店随机抽到该阵容的概率已验证。

## 扩展边界

- `scripts/data/escort_map.gd`：可通行地块、A→B路线、营地和来敌入口。当前路线12次移动、四段、唐僧步进间隔2.5秒、敌人逐个2秒预告，均为试验值。
- `scripts/escort_route.gd`：新主入口实时指令、护送进度、驻守战斗与地形显示；继承旧 `game.gd` 复用经营和攻击链。无群选、自动跟随、手动技能或新章节存档。
- 当前已验证源工程与导出资源包启动；此前 `0.1.0-playtest.1` Windows ZIP 仍为旧固定棋盘，不能当作本次新玩法包。新导出预设已包含移动护送入口，但本轮没有重新分发 Windows ZIP，也没有 Windows 实机验收。

- `scripts/data/`：英雄与单场波次配置；临时数值与正式设计分开。
- `scripts/presentation/`：共享动作、素材加载、发射点、占位音效。
- `scripts/combat/attack_events.gd`：动作序号、投射物与单次命中队列。
- `unit.gd`、`enemy.gd`：单位状态；`game.gd`组合商店、布阵与战斗。
- 后续章节状态与存档从此处扩展；不要求重做动作播放器。
