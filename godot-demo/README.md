# 《今晚别偷粮》Godot Demo

一个“棋盘塔防 + 三合一升星”的可玩原型。玩家购买玉米、辣椒、土豆和咖啡守卫，保护左侧粮仓，抵挡8波老鼠。

## 环境

- Godot 4.7.2 Standard
- GDScript
- Compatibility 渲染模式
- 设计分辨率：1280×720

## 打开和运行

1. 启动 `C:\software\Godot-4.7.2\Godot_v4.7.2-stable_win64.exe`。
2. 点击“导入”，选择本目录中的 `project.godot`。
3. 打开项目后按 F6 或 F5。

也可以在命令行运行：

```powershell
& 'C:\software\Godot-4.7.2\Godot_v4.7.2-stable_win64_console.exe' --path '项目目录' --editor
```

运行自动冒烟测试：

```powershell
& 'C:\software\Godot-4.7.2\Godot_v4.7.2-stable_win64_console.exe' --headless --path '项目目录' --script 'res://tests/smoke_test.gd'
```

## 操作

- 点击底部商店卡片购买单位，单位会进入备战区。
- 按住单位拖入3×6棋盘，也可以在棋盘和备战区之间移动。
- 三个同种、同星级单位会自动合成，最高三星。
- 点击单位可查看属性并出售。
- 点击右下角按钮开始下一波。
- 守住8波获胜；粮仓生命降到0则失败。

快捷键：

- `1` / `2` / `3`：购买对应商店单位
- `R`：花费5金币刷新商店
- `Space`：开始下一波
- `Esc`：取消单位选择
