# 西游护送 · 单战 Demo

这是用于验证核心玩法的单场可玩原型：唐僧位于 5×7 棋盘中央，玩家先用金币招募、合成和布置三名队员，开战后双方自动走格、攻击并释放技能。整场包含 4 波敌人，最后一波为虎先锋 Boss。

画面暂时采用明亮国风 Q 版方案，人物约三头身。当前角色图和场景图是 Demo 素材，最终画风尚未确认。

## 运行环境

- Godot 4.7.2 Standard
- GDScript
- Compatibility 渲染模式
- 设计分辨率 1920×1080，默认窗口 1440×810

## 运行

在仓库根目录执行：

```bash
godot --path godot-demo
```

打开编辑器：

```bash
godot --editor --path godot-demo
```

如果命令名是 `godot4`，将上面的 `godot` 换成 `godot4`。也可以在 Godot 项目管理器中导入 `godot-demo/project.godot`，进入编辑器后按 F6 或 F5。

## 推荐体验流程

1. 购买商店前三只玉兔，它们会自动合成为一只二星玉兔。
2. 再购买青羽弓手和铁角护卫。
3. 将三名队员拖到唐僧周围；也可先点击队员，再点击棋盘格。
4. 点击“开始战斗”，观察四波自动战斗和战后星级结算。

## 操作

- 鼠标点击商店卡片招募；数字键 `1`—`5` 也可购买对应卡片。
- 拖动候选区或棋盘上的队员改变位置。
- 中央唐僧所在格不能部署队员。
- `R` 刷新商店；进入本关有一次免费刷新，之后每次 2 金币。
- `E` 升人口；初始 3 人口，3 升 4 需要 10 金币。
- 点击队员可查看属性、技能、出售价格和合成锁定状态。
- 三个未锁定的同名同星队员自动合成，最高三星。
- `Space` 开始战斗；战斗中用于暂停或继续。
- 战斗中可点击“暂停/继续”和 `1×/2×`。

## 已实现内容

- 5×7 棋盘、中央唐僧和鼠标优先布阵
- 5 格商店、8 格候选区、金币、刷新和升人口
- 白/绿/蓝品质和对应价格、低人口品质概率
- 五名可招募英雄、自动三合一、合成锁定、折价出售
- 一星主动技能、二星新增被动、三星新增效果的技能展示
- 敌人走格逼近唐僧，队员有限追击，双方自动普攻和施法
- 4 波战斗、3 秒波次预告、暂停、1×/2×
- 灰鼠、山猪、黑狼精英与虎先锋 Boss
- 击杀金币暂存，战后按唐僧血量评星并结算
- Boss 击败解锁提示和完整重玩流程
