# 正面棋盘与角色正背面动作

2026-10-17。按负责人要求，将松风台改为不横向旋转的正面45°斜俯视，并为当前10个角色接入正、背面基础关键姿势。运行入口仍是 `godot-demo/launch-board-trial.command`；默认护送、旧矩形棋盘和独立狐火三维试场不变。

## 本轮范围

棋盘保持12×7，投影为 `O=(246,274)`、`U=(106,0)`、`V=(0,106/√2)`，不再横向偏斜。前沿台侧厚40逻辑像素，有台阶与两侧灯柱。绘制和鼠标点选使用同一投影及逆变换；台侧不是可走格。

唐僧、护寺棍僧、山野猎户、山雀精、药灵童子、狐火小妖、山狼、山猪、灰鼠和熊山君均有16个取用姿势。每个方向8姿势：待机、移动接触、移动经过、攻击起手、释放/接触、受击、开始倒下、倒地。前8为正面斜俯，后8为真实背面斜俯；左右通过引擎镜像形成四个视觉朝向，不是八方向独立绘制。

移动依据实际0.50秒走格选择姿势；攻击仍使用原命中时钟。停步保留朝向，死亡冻结朝向。身体、阴影、脚点、发射位置共同读取同一帧；不通过压扁角色制造俯视。新入口停用旧“棍僧新版/旧版”假对照，真正旧样板仍在legacy入口。

## 美术资产与边界

全部PNG使用内置图像生成工具制作并保留原始透明像素。没有把《将熄之焰》的图像或模型复制进游戏；其[官方画面](https://store.steampowered.com/app/1830970/The_Last_Flame/)只用于镜头空间关系参考，45°是本项目的选择，不是对参考游戏相机参数的测量。

角色目录内 `atlas.png` 是16姿势原图，`manifest.json` 保存实际取样框、脚点、接触点及发射位置。棍僧、猎户、狐火额外有 `move-atlas.png`，仅替换正背面的移动经过姿势；同张替换图使用统一源分辨率倍率，不逐姿势调整体型。药灵、狼、唐僧的相邻外框局部相交，采用带留边的UV多边形取样，原图不裁改，避免绘入邻格。

这是**可运行的关键姿势版**，不是完整逐帧动画或骨骼动画：两张移动姿势不能代表完整左右交替跑步循环，转向切换仍有跳变，镜像会交换非对称装备的视觉左右。手绘姿势之间仍有服饰和体量细节差异；后续精修需要补中间帧或以统一三维模型渲染，不应继续靠无限重抽16宫格解决连续性。

## 检查与复现

`geometry-review.json` 是10角色、160取用帧、13张图集的静态审计：覆盖取用主体、无邻格主体混入、透明像素边界、源图哈希和脚点范围。`inspect_atlas.py` 只读PNG并计算元数据，不改写图片。原图未采用的重复步态仍保存在原atlas内并明确排除。药灵/狼初始候选与运行原图相同，候选记录仅引用同一份文件，不重复存图。

运行验证证据在 `review/`。几何、方向事件、完整战报及正常窗口交互分别验证；作者自测和协作只读复核不替代07正式验收或负责人真人体验。未测Windows实机，也不以截图或15FPS预览宣称运行性能。

## 生成记录

`correction-prompts.json` 保存唐僧去重法杖、山雀羽冠留白及未采用棍僧步态尝试的实际提示词；`passing-prompts.json` 保存三角色移动经过姿势实际提示词。熊、猪、灰鼠目录的 `PROVENANCE.json` 保存各自完整调用记录。其余首轮图的共同制作规格见 `PROMPT_SPEC.txt`；该文件是整理后的复现规格，不冒称逐字调用日志。生成带随机性，复用提示词不能保证逐像素复现；已入库PNG与哈希才是跨机器权威成果。
