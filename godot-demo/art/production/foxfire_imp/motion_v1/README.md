# 狐火小妖施法过渡候选

更新时间：2026-09-11；职责：05｜美术。

从已审核 `concepts/foxfire_imp/foxfire_imp_action_keypose_sheet_v1.png` 补画 8 个连续姿势：准备待机、聚力、蓄力、伸手、释放、随势、收手、恢复。同一镜头朝向下，尾巴均留在身体同一侧，减小原待机与攻击之间的方向跳变。属于试玩候选，原概念图和 `demo_v1` 保留，未作为正式造型验收。

生成源图 `generated-sheet.png` 为带绘制棋盘底的 RGB；运行时使用已清底的 RGBA 单帧及 `body-atlas.png`。图集 2048×256、单帧 256×256，脚底锚点 `(128,218)`。生成要求沿用原脸型、长耳、橙色额纹、铃铛腰带、黑袍与围巾，不绘制独立火球、地线和特效；同一侧尾巴仅轻微随动。暖色毛发与手部亮色保留。

`manifest.json` 记录源图哈希、落脚点、逐帧手部坐标和施法时间轨。`tools/build_foxfire_motion.py` 调用公共提取流程重建；需要 Pillow、NumPy。全角色未重新缩放，只有此候选使用固定的 124/372 比例。

独立棋盘试玩默认使用新准备待机和施法序列，移动/受击/退场沿用旧包；M 可即时回到旧版对比。火焰用现有独立素材附着于逐帧手部点，释放时使用同一个坐标生成飞弹。释放后手上不重复显示整枚火球；火焰不参与身体清底和脚底尺寸测量。

已验证：8 帧透明底与深浅底复核、实际播放覆盖、命中图不提前、左右朝向掌心发射点一致、30/60/120 FPS 战斗时长与事件一致；Godot 连续对比与更新后的棋盘截图复核通过。实机对比：`reviews/six-role-battle/frame-comparison-foxfire.gif`，左旧右新；开关不改变伤害或攻击间隔。

仍待精修：新图有线条/细节重绘差异，聚力时手型和衣袖仍可更稳定；移动、受击、退场尚未采用统一朝向的过渡序列。未新增正式技能或技能特效。
