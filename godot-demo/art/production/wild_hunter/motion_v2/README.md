# 山野猎户收刀衔接 v2

更新时间：2026-09-12；职责：05｜美术；状态：独立试玩候选。

新增 4 张实际姿势：屈肘收刀、下放猎刀、回位、站稳。图集 3072×256，含原 motion_v1 的 8 张和新增 4 张；单帧 256×256，脚底锚点 `(128,218)`。原概念图、demo_v1、motion_v1 均保留，前 8 格像素不变。本版默认用于六角色独立试玩，关闭补帧仍显示 demo_v1。

## 动作衔接

旧攻击结束时直接换成正面待机，脸、刀和尾巴的朝向发生突变。现在命中帧 6 接新增 8～11 帧，末收势、待机、下一次起手共用第 11 帧；旧收势 7 留在图集中但不再夹入新回收序列。回收前段从 96% 身高逐渐站直，保持脚底支点与原攻击时长。

第一张生成候选的首格换了持刀手，未采用。经定向修改后，四格均由角色右手持刀，尾巴保持同侧，再清底打包。新旧衣纹、刀形和握点仍有细节差异，属于动画候选，不替代已审核原画。

## 来源与重建

imagegen 依据猎户已有运动稿及角色参考补画四格收刀序列，并修正首格持刀手。修正后的源图保存在 `generated-recovery-sheet.png`，为带绘制棋盘底的 RGB；本地轮廓提取、清底和缩放后输出 RGBA。

使用带 Pillow、NumPy 的 Python 执行 `godot-demo/art/production/tools/build_hunter_recovery.py`。复用收势打包函数，按人工脚底投影和统一比例整理；manifest 保存源图哈希、旧图集哈希、刀尖参考点和播放时间轨。公共打包函数重构已在临时目录重建棍僧，确认其输出像素和清单内容不变。
