# Demo 野猪五基础姿势透明包

2026-09-28，05 美术。沿用原 Demo 双足绿金护甲野猪；静态包可交程序试接，尚未修改运行代码。

## 内容与接口

- 五张 256×256 RGBA：idle、move、attack_impact、hit、retreat。
- `boar_demo_body_atlas_v1.png`：1280×256 横排，manifest 帧号顺序同上。
- 地面投影锚点 (128,218)，源图向左。sheet 统一缩放 .32，独立大图受击缩放 .16，非各格拉满画布。
- `manifest.json`：与山狼同结构五状态接口，basic_attack 暂复用待机作准备；无独立特效。
- `review-light-dark.png`：实际 alpha 合成浅深底，不把透明像素隐藏 RGB 当残底。
- 重建：带 Pillow 的 Python 执行 `art/production/tools/build_demo_boar.py`。

## 验证与限制

五帧尺寸、透明留白、图集与单帧像素一致、五状态映射检查通过；浅深底复核未见明显残底、相邻格碎片或主体裁切。移动手臂和攻击锤头靠近分界，采用折线分区，不按等宽列机械裁切。攻击前探挥锤，受击闭眼屈膝抬空手，轮廓可区分；持锤手及主护肩同侧。

不是完整动画：每状态一张关键姿势，无双步循环或收势中间帧。锤头铆钉、面部细节略有漂移；受击以低头防御为主，并非夸张后仰。06 接入须检查左右翻转、棋盘体量、实际脚点、挥锤接触点和状态切换；时长仅展示占位，不是玩法定案。
