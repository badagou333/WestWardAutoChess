# 护寺棍僧收势衔接 v2

更新时间：2026-09-11；职责：05｜美术；状态：独立试玩候选。

新增 4 张实际姿势：下压收棍、转棍、回到斜持、站稳。新图集 3072×256，含前版 8 张图加本批 4 张图；单帧 256×256，脚底支点 `(128,218)`。前版 8 帧像素保持原样，原概念图、demo_v1、motion_v1 均保留。v2 默认用于独立试玩；关闭补帧仍显示最初 demo_v1。

## 解决的问题

motion_v1 的末帧仍横持短露出的棍身，攻击结束直接换成斜持待机，武器和脸朝向突然变化。本批把新的连续回收姿势接在命中之后，最后一张站稳图用于收势结束、待机以及下一次攻击起始，去掉结束边界的换图。

第一次慢速复核还发现：若保留前版第 7 帧在新序列前面，棍头会先回缩、再伸出。已从 v2 攻击序列移除该旧收势，直接从第 6 帧命中转入第 8～11 帧回收。第 7 帧仍保留在图集中用于追溯。起身阶段增加轻微渐进展体，弥合旧命中蹲姿与新回收姿势的高度差，不改变脚底位置。

## 来源与重建

imagegen 以 `motion_v1/generated-sheet.png` 和已审核概念稿 `concepts/guard_monk/guard_monk_action_keypose_sheet_v2.png` 为参考，补画 2×2 四帧回收序列。要求同一脸型、服装、身体比例和双手持同一根直棍，从水平持棍逐步回到左高右低的斜持待机，固定镜头、无地线/阴影/特效。生成源图仍为绘制棋盘底 RGB，本地清理后输出真正 RGBA。

使用带 Pillow、NumPy 的 Python 执行 `godot-demo/art/production/tools/build_monk_recovery.py`。该工具提取独立轮廓、按人工脚底投影和统一比例对齐，保存源图/旧图集哈希、帧信息、棍头参考点及动作时间轨。新帧绘制细节有差异，不能视为正式原画替换。

## 验证

- 新图深浅底检查与边界检查通过，前 8 帧和 motion_v1 图集像素完全相同。
- Godot 播放了配置的移动/攻击帧，旧第 7 帧未再夹入回收；两朝向的末收势、待机、下一次攻击起始均是同一张第 11 帧，回位边界没有位置跳变。
- 六角色专项通过，30/60/120 FPS 均 20.70 秒、伤害/治疗等事件计数一致；原冒烟和四波回归通过。
- 实机 0.5× 对比：`reviews/six-role-battle/frame-comparison-monk-recovery.gif`，左为 motion_v1，右为本版；通过复核后更新正常速度实战 GIF 和棋盘截图。
