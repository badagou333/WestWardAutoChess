# 护寺棍僧 Demo 五基础动作样板 v1

## 用途

本目录把已审核的 `guard_monk_action_keypose_sheet_v2.png` 整理为可供程序接入的透明关键姿势资产，用于快速验证待机、移动、普通攻击、受击和退场五个基础状态。

这是“关键姿势切换 + 运行时位移/缓动”的 Demo 样板，不是完整逐帧动画。所有图片均由当前动作稿机械裁切、去除浅灰背景、统一缩放和落脚点后得到，没有重新生成或改画角色。

## 文件

- `guard_monk_idle_v1.png`：待机姿势。
- `guard_monk_move_v1.png`：移动接触姿势；移动位移和轻微起伏由运行时处理。
- `guard_monk_attack_prepare_v1.png`：普通攻击蓄力。
- `guard_monk_attack_impact_v1.png`：普通攻击横扫命中。
- `guard_monk_hit_v1.png`：受击姿势。
- `guard_monk_retreat_v1.png`：退场跪地姿势。
- `guard_monk_demo_pose_atlas_v1.png`：以上六帧按同样顺序横向排列的透明图集，单帧 256×256。
- `guard_monk_demo_action_board_contact_v1.png`：六帧按真实棋盘显示高度合成的 3×2 预览；从左到右、从上到下依次为待机、移动、普攻蓄力、普攻命中、受击、退场。
- `manifest.json`：帧序、锚点、建议时长和接入备注。

## 统一规格

- 单帧尺寸：256×256 像素，透明背景。
- 脚底锚点：`(128, 218)`，所有状态不得按图片中心重新对齐。
- 待机外接框高度：约 144 像素；接入当前 1920×1080 Demo 时建议保持 1:1，不再额外缩放。
- 普攻使用两帧：蓄力 → 命中；动作结束后回到待机。
- 棋盘遮挡按角色所在行排序，不按人物图片高度排序。

## 已验证与限制

- 六帧均为 256×256 RGBA PNG，长棍、衣摆和脚底没有碰触帧边界。
- 原动作稿并非严格等宽网格，不能直接按四等分切图；本样板已逐姿势独立裁切并移除邻格碎片。
- 普攻命中帧目前保留原稿中的干笔运动弧线，只用于 Demo；正式资产应把弧线拆成独立 VFX。
- 待机与移动目前各只有一个关键姿势，需要运行时轻微呼吸、上下起伏和棋盘位移才能形成最小可用动画。
- 本样板不包含背 3/4 朝向、完整中间帧、骨骼绑定、技能动作或正式 VFX。

## 建议接入节奏

- 待机：单帧循环，叠加约 2 像素呼吸起伏，周期 0.8 秒。
- 移动：单帧循环，叠加棋盘位移与约 2 像素上下起伏，周期 0.4 秒。
- 普攻：蓄力 0.12 秒，命中 0.16 秒，随后回到待机。
- 受击：保持 0.18 秒，随后回到待机；不做击飞。
- 退场：跪地过渡 0.45 秒，随后淡出 0.25 秒。
