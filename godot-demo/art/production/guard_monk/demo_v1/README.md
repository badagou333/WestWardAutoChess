# 护寺棍僧 Demo 五基础动作样板 v1

## 用途

审核状态（2026-09-08 修复）：六帧已从确认版八动作稿重新提取，腿间、武器围合区域及轮廓灰白残底已清理，蓄力棍头和横扫左侧脚部已补回；深浅底静态复核通过。各帧统一缩放并标注身体落地点，动态对齐与正式战斗仍待验证。本条替代 2026-09-05 对旧加工结果的未通过结论，不代表完整动画验收。

本目录把已审核的 `guard_monk_action_keypose_sheet_v2.png` 整理为可供程序接入的透明关键姿势资产，用于快速验证待机、移动、普通攻击、受击和退场五个基础状态。

这是为“关键姿势切换 + 运行时位移/缓动”准备的静态素材包，统一网页已有五状态预览，正式战斗效果尚未接入，也不是完整逐帧动画。所有图片均由当前动作稿机械裁切、去除包括封闭空隙在内的浅灰背景并统一缩放后得到，没有重新生成或改画角色。

## 统一规格

- 单帧尺寸：256×256 像素，透明背景。
- 建议脚底锚点：`(128, 218)`。本次使用逐姿势手工标注的身体落地点，六帧保持相同缩放；仍需动态检查承重与位移表现。
- 待机外接框高度：约 140 像素；接入当前 1920×1080 Demo 时建议保持 1:1，不再额外缩放。
- 普攻使用两帧：蓄力 → 命中；动作结束后回到待机。
- 棋盘遮挡按角色所在行排序，不按人物图片高度排序。

## 已验证与限制

- 六帧为 256×256 RGBA PNG，图集与单帧逐像素一致，边界留白；源图哈希不变。除尺寸检查外，已对照完整源图和深浅底预览复核蓄力棍头、横扫脚部及弧线，避免仅凭最终边界留白判断裁切。
- 腿间和挥棍弧线内原有大块灰底已清除；三个原稿坐标对应的封闭残底采样点 alpha 为 0。深浅底目视复核保留脸部暖白毛色。此检查不是逐像素手工精修或用户最终验收。
- 原稿并非等宽网格；本次使用独立多边形裁切，避免相邻姿势棍头/衣片串入。该角色阈值和标注不应直接套到其他角色。
- 普攻命中帧目前保留原稿中的干笔运动弧线，只用于 Demo；正式资产应把弧线拆成独立 VFX。
- 待机与移动目前各只有一个关键姿势，需要运行时轻微呼吸、上下起伏和棋盘位移才能形成最小可用动画。
- 本样板不包含背 3/4 朝向、完整中间帧、骨骼绑定、技能动作或正式 VFX。

## 建议接入节奏

以下均为待动态验证的提案，不代表已经实现或由项目负责人确认。

- 待机：单帧循环，叠加约 2 像素呼吸起伏，周期 0.8 秒。
- 移动：单帧循环，叠加棋盘位移与约 2 像素上下起伏，周期 0.4 秒。
- 普攻：蓄力 0.12 秒，命中 0.16 秒，随后回到待机。
- 受击：保持 0.18 秒，随后回到待机；不做击飞。
- 退场：跪地过渡 0.45 秒，随后淡出 0.25 秒。

## 本次复现与范围

运行 `python godot-demo/art/production/tools/build_guard_monk_demo.py`（需 Pillow 和 NumPy），自动重建六帧、图集、深浅底预览及统一网页配置。旧文件名保留以兼容已有入口。当前源图仍为已确认的八动作稿；另存的六姿势修正候选未在本轮替换为视觉基线。狐火样板未修改。
