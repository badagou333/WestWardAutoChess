# 熊山君连续收棒 v2

更新时间：2026-09-12；职责：05｜美术；状态：独立试玩候选。

新增 4 张收棒/站稳姿势：屈肘回收、下放棒头、回位、站稳。图集 3072×256，共 12 格，单帧 256×256，脚底锚点 `(128,218)`。前 8 格与 motion_v1 像素相同；已审核概念图、demo_v1、motion_v1 均保留。

## 解决的问题

旧攻击结束后会直接从双手低持棒切成单手扛肩待机，身体和武器明显跳变。现在命中格 6 接新增 8～11 格，回收后保持双手低持；最后收势、待机、下一次起手共用 11。旧收势格 7 留在图集中供追溯，不再插入本版时间轨。起身阶段使用轻微渐进展体，攻击时长、伤害释放时刻和数值保持。

## 来源与重建

使用内置 imagegen，以 `motion_v1/generated-sheet.png` 为动作连续性参考、`concepts/bear_lord/bear_lord_action_keypose_sheet_v1.png` 为身份参考补画。要求四格同一镜头/朝向/双手持棒，从伸展命中逐步收至腰前低持，不扛肩、不换手、不添加地线或特效；完整提示词保存在 `generation-prompt.txt`。

生成源图为带绘制棋盘底的 RGB，保存于 `generated-recovery-sheet.png`。用户已授权的本地清底和逐姿势打包输出真正 RGBA。使用带 Pillow、NumPy 的 Python 执行 `godot-demo/art/production/tools/build_bear_recovery.py`，按人工地面投影与统一比例整理，manifest 保留来源哈希、棒头参考点与动作时间轨。
