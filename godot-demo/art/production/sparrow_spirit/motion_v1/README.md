# 山雀精展翼施法过渡候选

更新时间：2026-09-13；职责：05｜美术。仅用于独立六角色试玩；原造型参考、`demo_v1`、正式技能和主 Demo 均保持。

新增八张连续姿势：准备、抬翼、聚拢、展翼、释放、随势、收翼、放下。近侧羽翼在胸前展开并向右扫出，双脚保持落地支撑；收势尾段回到第 0 帧，待机和下次起手同图，改善旧准备/腾空出手/站立之间的突变。是短施法动作候选，不是完整走路或方向动画。

来源为内置 imagegen，唯一身份/风格参考是当前 `sparrow_spirit_action_keypose_sheet_v2.png`；完整提示在 `PROMPT.md`。生成输出 `generated-sheet.png` 为 RGB 实色棋盘底，已使用项目授权的公共流程提取角色，输出八张 256×256 RGBA 与 2048×256 图集。深浅底预览为 `contact-dark-light.png`。宽翼会跨原图等分格线，提取按独立连通轮廓进行，不机械等分裁切；全序列统一缩放 `120/427`，身体落脚投影人工标记并对齐 `(128,218)`。

`manifest.json` 新增逐帧 `emission_sockets`，释放帧的坐标对应前缘羽尖。独立试玩在同一释放时刻用当前绘制变换生成既有风刃，不在身体上重复绘制风刃，不添加蓄力火焰。狐火/药灵继续走原手掌附着配置。攻击间隔、伤害量、固定飞行时长及目标逻辑保持；风刃仍只是试玩占位，不确认正式技能采用风刃或箭矢。

验证通过：

- 八个不同姿势、单帧与图集逐像素一致、源图完整边界及最终透明余量、羽尖标注附近存在有效羽翼像素；深浅底复核无大块残底或截断。
- 八帧均实际播放，释放帧与事件同步；左右朝向飞弹均从羽尖生成，准备期不发射，抵达只造成一次伤害。收势末尾/待机/起手同图且落脚点无边界位移。
- 独立六角色专项通过；30/60/120 FPS 均 20.70 秒，事件计数与上一版一致。原冒烟与完整四波回归通过（47.7 秒、唐僧 300/300、战利品 20）。
- 真实 Godot 半速对比与正常速度战斗采样、开场/交战/退场截图复核；两朝向发射由专项测试覆盖，半速对比图展示右向动作。

观看 `../../../reviews/six-role-battle/frame-comparison-sparrow.gif`（左旧右新，0.5×）或运行独立 `battle.tscn`，M 切换补帧。重建运行 `godot-demo/art/production/tools/build_sparrow_motion.py`，静态验证运行同目录 `verify_sparrow_motion.py`，依赖 Pillow/NumPy；动态验证与渲染命令见试玩 README。

限制：候选有羽片、衣纹与头冠细节重绘差异，展翼幅度和部分中间姿势的身体高度仍可精修；与旧腾空移动、受击/退场尚无新增过渡。未改变正式造型定案，也不代表全方向、全部遮挡场景或完整动画验收。
