# 药灵童子施法过渡候选

更新时间：2026-09-13；职责：05｜美术。仅用于独立六角色试玩，正式造型参考、原 `demo_v1`、玩法与主 Demo 基线保持。

新增 8 张肢体姿势：准备、抬手、聚力、伸掌、释放、随势、收手、放下。药杖在画面左侧持续由同一只手握住，自由手在右侧施法；脚掌保持支撑，结束回到第 0 帧，待机及下次起手也使用第 0 帧。修复旧版待机突然切横杖施法的跳变。此为施法表现候选，不新增正式技能。

原图参考只用于角色身份与风格，八个姿势由内置 imagegen 补画；完整提示词在 `PROMPT.md`，源图在 `generated-sheet.png`。生成的 RGB 棋盘底已用现有授权流程移除。单帧 256×256、图集 2048×256、脚底锚点 `(128,218)`，统一源图缩放 `142/452`。源图身体支点及掌心坐标人工标记于 `../../tools/build_herbal_motion.py`，不按全图外接框中心对齐。

逐帧掌心坐标供已有治疗投射物发射；蓄力仅复用原 `idle_mist`，释放后不在手上保留重复投射物。药灵坐标偏移为零；狐火继续保留原上移 8 像素偏移。原攻击时序、治疗量、投射物飞行时间和移动/受击/退场不变。试玩 M 开关可回到原姿势对比。

验证通过：

- 8 个独立姿势、单帧与图集逐像素一致、源图轮廓边界和最终帧透明余量、掌心落在身体有效区域；深浅底复核没有旧样板的大块灰底与截断。
- 实际播放覆盖全部 8 帧；释放帧与事件同步，两朝向飞弹起点都位于当前掌心；蓄力不治疗，抵达只治疗一次。
- 收势末尾、待机、下次起手同帧，脚底位置在边界保持；独立六角色专项无失败。
- 30/60/120 FPS 仍为 20.70 秒，事件计数相同，且与上一版一致；原 `SMOKE_TEST_OK`、`FULL_BATTLE_TEST_OK` 通过，四波 47.7 秒、唐僧 300/300、战利品 20。
- 真实 Godot OpenGL 半速对比采样、正常速度实战采样和开场/交战/退场截图复核。对比动图为 `../../../reviews/six-role-battle/frame-comparison-herbal.gif`，左旧右新；实战预览为同目录 `motion-preview.gif`。

重建：在仓库根使用带 Pillow/NumPy 的 Python 运行 `godot-demo/art/production/tools/build_herbal_motion.py`，随后运行同目录 `verify_herbal_motion.py`。独立场景验证与渲染命令见试玩 README 的复现部分。

限制：新图的衣纹、帽饰与线条有重绘差异，与旧移动/受击/退场仍有衔接差异；八帧是短施法序列，伸手幅度还可精修。没有新增走路双步或方向过渡，也不意味着正式动画或造型已验收。
