以 `board_trial_config.gd` 为几何与阵容权威：1920×1080逻辑画布，棋盘Rect(220,190,1320,714)，110×102格，12×7，战前左6列。布局预览不改变游戏配置。

| 区域 | 表现与内容 |
| --- | --- |
| 顶部 | 左侧标题/唐僧HP，中间阶段，右侧暂停/倍速/帮助；移除常驻内部版本号和长反馈横条 |
| 左侧窄边 | A/B/C既有样例，小段操作提示；完整规则按需展开 |
| 中央 | 现有84格；部署/选中/曼哈顿射程分层绘制，场景静态图不得烘焙这些标记 |
| 右侧上部 | 山狼/山猪/灰鼠三类头像与数量，点选可查看具体属性；将重复长敌阵文字收起 |
| 右侧下部 | 选中人物头像、HP、攻/疗、射程、间隔、状态、格位；R撤下只适用于己方战前 |
| 底部 | 六个固定队员头像卡，编号、名称、HP条与部署状态分层；不是招募商店或新增替补名额 |
