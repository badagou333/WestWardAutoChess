# 角色棋盘尺寸测试

## 当前测试图

- `character_board_scale_test_v1.png`：六名角色分散放入当前 5×7 棋盘，用于比较角色体量、轮廓和职业辨识度。上排从左到右为护寺棍僧、药灵童子、山雀精；下排从左到右为熊山君、山野猎户、狐火小妖。
- `character_board_density_test_v1.png`：保留中央唐僧，并将六名角色放在相邻格形成密集阵型，用于检查前后排遮挡、落脚点和中心护送目标的辨识度。

两张图均使用当前 Demo 的 1920×1080 画面、5×7 棋盘、162×113 像素格子和真实格子中心位置。角色从当前动作稿的待机姿势机械裁切、去除浅灰背景后叠放，没有重画或改变造型；本文件仅用于视觉审核，不是可直接导入游戏的 Sprite 或运行时代码。

## 本轮建议显示高度

- 护寺棍僧：144 像素。
- 药灵童子：142 像素。
- 山雀精：120 像素。
- 熊山君：164 像素。
- 山野猎户：136 像素。
- 狐火小妖：124 像素。

以上数值按透明角色外接框计算。在当前 1440×810 窗口中会整体缩放为约 75%，熊山君仍保持最大体量，山雀精与狐火小妖保持轻小，但不再缩小。

## 审核结论

- 六名角色的体量层级和待机剪影可以区分；护寺棍僧的长棍、药灵童子的斗笠药杖、熊山君的大体块、山野猎户的猎刀、山雀精的羽翼和狐火小妖的白头橙火均能保留身份特征。
- 密集阵型中相邻角色不会越过两个格子，但下排角色会自然遮挡上一排脚部；运行时必须按棋盘行排序，并统一以脚底为锚点。
- 当前尺寸不建议继续整体放大；再放大会明显压缩相邻格留白，并增加熊山君、护寺棍僧武器与邻格角色的遮挡。
- 当前主要风险是画风和值域而非尺寸：暗色手绘角色在明亮高饱和 Q 版棋盘上轮廓很清楚，但衣服内部细节容易缩成黑块，并与现有唐僧占位图明显不统一。
- 为快速完成 Demo，可以暂用当前棋盘并保留统一脚底阴影、血条和选中圈；制作正式角色 Sprite 时适度抬高深色衣物中间调。最终美术生产前仍需统一棋盘、唐僧和角色的画风。

## 推荐下一步

先以护寺棍僧作为首个五基础动作生产样板，验证长武器裁切、脚底锚点、前后排排序和受击/退场播放；样板通过后，再以狐火小妖验证角色与投射物/VFX 分层。
