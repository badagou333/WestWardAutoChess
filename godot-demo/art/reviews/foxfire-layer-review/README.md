# 狐火小妖分层样板复审

日期：2026-09-08；职责：05｜美术 / 角色 / UI。

## 结论

分层结构和独立预览中的五状态切换可用，可供程序试接入；美术加工验收未通过。须清理封闭缝隙残底与受击地面笔触，再核对身体锚点。不能按已验收正式素材或批量生产模板交接。

本轮未修改原 PNG、生产清单或运行时代码，也未完成 Godot 正式战斗接入。原动作参考的审核状态不变。

## 需要修复或继续校准

1. **清底残块**：深色背景 3 倍预览中，蓄力帧尾巴与身体/衣带缝隙、发射帧后侧衣袖与尾巴间、受击帧衣袖与尾巴间可见亮色封闭残块。应对照原稿逐区域清理，不能按“所有亮色都是背景”机械删除，以免误删白毛。
2. **受击地面笔触**：受击身体帧脚下保留浅色地面划痕，随身体一起出现；退场残火底部也有短地线。需清理或明确拆为独立效果，避免地面随角色漂移。
3. **身体锚点证据不足**：alpha≥10% 的各身体外接框底端集中在 y=218～219，但受击底端包含地面笔触。统一 `(128,218)` 不能证明支撑脚已校准；最低六行可见像素横向范围随动作变化较大，只能作为检查线索，不能直接据此自动位移。应在清底后根据身体/支撑点重新确认。
4. **动作切换方向与轮廓**：待机尾巴位于画面右侧，移动和普攻转至左侧，回待机时有明显轮廓切换。可作为 Demo 姿势切换候选，正式动画需统一朝向或补过渡，不在本轮重画。
5. **接入信息**：原 manifest 未定义施法点；预览采用试验值 `(190,154)`（256 帧坐标），不是用户确认数值。生成独立投射物时不再显示第 3 格同帧飞弹，否则重复。身体回待机后待机火焰与飞行中的投射物可以同时存在，它们是两个不同用途的效果。

## 复现与文件

- `audit.gd`：Godot 4.7.2 原 PNG 审核脚本；`audit-results.json` 是本批数据证据。
- 在仓库根目录运行：`godot --headless --path godot-demo --script res://art/reviews/foxfire-layer-review/audit.gd`。本机需要用 Godot 可执行文件完整路径替代 `godot`；若用户目录不可写，添加指向可写绝对路径的 `--log-file`。审核的文件/图集检查失败返回非零；报告通过不覆盖上述视觉缺陷。
- `index.html`：浏览器独立审核页，支持动作选择、特效开关、深浅底色、慢速、暂停及进度定位。可直接打开；若浏览器限制本地资源，从 `godot-demo/art/` 启动本地 HTTP 服务，再访问 `/reviews/foxfire-layer-review/index.html`。
- 左侧以 1× 游戏逻辑像素和 162×113 示意格绘制，整个页面会随浏览器宽度缩放；右侧为 3×细节。不是实际 Godot 棋盘场景或按行排序验证。
- Godot 审核输出 `FOX_LAYER_AUDIT: files=14 atlas_checks=12 failures=0`；系统证书读取告警未影响本地 PNG 检查。

推荐下一步：先修复三帧封闭残底与受击地线，校准身体锚点，再由 06 验证 Godot 场景中的投射物发射点、目标追踪和按行排序。本轮不把程序试接入可行性等同于最终美术验收。
