# v3 验收记录

更新：2026-10-07。范围：狐火独立动画候选，重点修复负责人反馈的脚向和走路姿势，同时复核全身连接、形变与起停。

## 对 v2 结论的更正

负责人明确指出 v2 离可用仍有距离。复查发现：原两张腿图的脚尖方向本来不同；两脚前后关系没有真正交换；两个半步幅度不均。旧检查选取了透明边缘作为「脚底」，其漂移数值不能证明真实脚掌不滑。旧记录的数值通过和原生播放成功，均不足以支持步态质量通过。v2 历史文件保留，本版取代其作为最新评审候选。

## 本轮标准与结果

| 观察目标 | 验收方法 | 本轮结果 |
|---|---|---|
| 脚向一致，脚掌不扭曲 | 朝左原图、8 个步态姿势、原生两半步抽查 | 两脚共用同向新图，脚掌区保持刚性，前后脚真实交换 |
| 能读出抬脚、前送、落地、承重 | 正常速度、半速、角色位移而地面不动的预览 | 两腿半周期错开，有双支撑期，无同时腾空；两个半步间距已收敛 |
| 支撑脚稳定，落地不穿地 | 从不透明脚掌轮廓提取接触点，行走 300Hz 几何抽样 | 支撑期漂移最大约 0.0241 原图像素；最小离地值约 −0.0241，仅为插值误差 |
| 膝踝和衣裤保持形体 | 网格有向面积＋大图视觉抽查 | 四种动作及起停中无可见翻面；行走可见网格最小面积比约 0.491/0.523，无明显塌缩 |
| 头颈、肩腕、衣摆、尾根连贯 | 接触表、流程/攻击代表帧与原生抽查 | 所查姿势无新增接缝裂口；身体、手臂、衣摆与尾巴小幅错时跟随 |
| 循环和固定起停无明显跳变 | 动作端点与 12 次固定状态变更检查 | 状态边界矩阵差 0；行走首尾脚速差约 0.217 原图像素/秒；选帧未见脚位突跳 |
| 攻击蓄力、离手、回位明确 | 释放瞬间矩阵/透明度/事件，普攻代表帧 | 0.48 秒交接连续，所查帧未重现火焰贴耳或重复火焰 |

脚掌测点使用真实不透明像素，接触点从 alpha≥128 的轮廓底部推导，另核查脚尖、脚跟和脚掌内部点。测点、阈值及逐项结果在检查脚本/JSON 中，不以骨头位置冒充可见脚底。

## 仍需保留的边界

本版是克制的小步走。宽裤腿与衣摆会遮住部分膝部，在 0.085 参考尺寸的经过姿势中，远腿仍有短暂遮挡；不能称为商业最终质量。

起停只验证固定循环边界。没有验证任意时刻中断、动态加减速、不同朝向、Godot 的实时混合、实际移动速度和攻击判定。短待机段为固定中性姿势。运行接入由 00 另排 06/07，05 仍须做正式视觉复核。

所有修改在 v3 候选及 09 工作流内；旧版、production 和游戏代码未变。Trial 的保存/导出限制保持，没有 `.spine` 工程，也没有绕过许可。
