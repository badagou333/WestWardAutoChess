**不能照旧v1把背景简单铺到Rect(0,0,1920,1080)**：这样底部台沿和左下角装饰离最后一排过近，外围留白检查框落到台沿上。第二次生成虽然改善了矩形地面，但未逐像素满足提示词；本批通过明确的显示映射校准，不宣称模型直接输出了精确几何。

具体映射是：完整源图横向映射1920、纵向映射1128、整体y=-12，再由1080高画布裁剪。相对铺满1080高的版本，纵向放大4.444%，裁去顶部12/底部36逻辑像素；不是等比缩放，也不是完整显示原图。源PNG未裁切、未重绘、未重编码，更不是从概念UI图裁出一块当纹理。只有背景使用该变换，单位、脚点、格线、镜头和输入坐标均不跟着拉伸。

映射公式：`screen_x = source_x × 1920/1672`，`screen_y = source_y × 1128/941 - 12`。棋盘覆盖源图x≈191.583..1341.083、y≈168.512..764.145；其内部可用地面无台阶/灯笼侵入。画中台沿只是装饰，操作外框由程序绘制。右侧地面延伸到侧栏下方，侧栏应用近不透明墨青底，不能让浅石纹干扰文字。
