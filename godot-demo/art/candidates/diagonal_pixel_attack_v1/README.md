# 斜向棍僧与山狼：像素攻击

2026-10-27。负责人要求沿用最新斜向站位，只做攻击，并逐帧检查。两角色限定离线逐帧及棋盘复核通过，待负责人真人观感确认。状态以[STATUS.json](STATUS.json)为准。

从[审阅页](review.html)查看正常速度、动作半速、四向菱格对照和全部显示阶段；[总览图](overview.png)用于快速比较。各角色的透明身体帧、带效果帧、图集、时序和完整来源分别在[棍僧包](monk/README.md)与[山狼包](wolf/README.md)。

| 角色 | 源方向 | 派生方向 | 动作 |
|---|---|---|---|
| 护寺棍僧 | SE斜前、NE斜后 | SW/NW水平镜像 | 提棍蓄势→快速压棍→接触停顿→回收，短棍影后置 |
| 山狼 | SE斜前、NE斜后 | SW/NW水平镜像 | 蓄身→张口探身→合咬→收头落爪 |

每个源方向6个身体姿势。镜像是展示派生，不计作新增手绘方向。脚底与身体体量使用固定画布、固定尺度；不按每帧轮廓自动放大缩小。1×预览菱格为192×96，两角色统一以448画布的0.5倍显示。

朝向只沿用[rect_iso_duel_v1双角色斜向待机](../rect_iso_duel_v1/README.md)，不沿用旧pixel_attack_series_v1的横向身体。该基准是斜前/斜后及约30°俯角的美术意图，不是精密标定的三维投影。旧系列曾因错误来源被撤回通过，不能由本包两个角色完成而恢复其他角色的状态。

真实新增图像均由内置imagegen绘制。项目保留原生输出的完整RGBA无损WebP、实际提示词、采用区域、失败修稿记录及可复建参数；局部保留原图用于稳住支撑足，棍僧背向独立后杆按前杆轴线放在身体后方。来源与具体修复以各角色说明为准。透明PNG是角色交付，预览GIF使用深色底。

本包离线检查涵盖逐帧、相邻姿势、手爪归属、武器连贯、脚下支撑、回收、菱格方向及镜像；技术检查包含透明/调色板、全帧及图集一致、正常/半速时长、原源无损和独立隔离重建。技术检查不会自动颁发视觉通过，且不能替代负责人真人连续观感或游戏内命中、遮挡、切换验收。HTML已检查链接与媒体；应用内file URL受浏览策略限制，未声称浏览器交互实测。

仅候选目录交付，没有制作受击或改运行程序。当前新增两个角色，不自动扩大为全员返工完成。

## 重建

使用已安装Pillow、NumPy的Python运行两个角色的rebuild.py，再运行tools/build_review.py。工具只读当前角色清单生成公共预览；本包tools/build_attack.py仅提供确定性编码和打包，不提供旧方向图片。公共中文标签使用本机字体，可用--font指定可用字体，不下载字体。

验证记录位于[公共审计](tools/review_integrity.json)及tools中的准备/重建审计文件。视觉结论只记已实际检查的范围，正式采用仍待负责人。
