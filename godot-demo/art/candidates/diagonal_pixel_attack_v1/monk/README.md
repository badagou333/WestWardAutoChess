# 护寺棍僧：斜向像素攻击

2026-10-27。SE斜前、NE斜后各6个身体姿势；SW/NW由对应方向镜像显示。离线逐帧及棋盘复核通过，待负责人真人观感确认；状态以[整包状态](../STATUS.json)为准。

朝向基准为[rect_iso_duel_v1](../../rect_iso_duel_v1/README.md)同向待机，保留黄袍、红腰带、獾脸和双头铜帽木棍。旧横向攻击仅提供已认可的节奏意图，不提供身体方向。2:1菱格为192×96，448×448角色画布以固定0.5倍在预览中显示，锚点(224,344)；没有逐帧按包围盒缩放。

身体姿势是准备、提棍、蓄势顶点、压棍接触、反弹、收势。第370ms从蓄势直接进入接触，不补拖慢出手的下落中间姿势；接触保持230ms。短残影为后置独立层，只在370～450ms以两档透明度出现，不挡脸和手。1070ms动作加400ms预览待机，正常1470ms；动作半速为2540ms，待机间隔保持400ms。每方向9个显示阶段，其中三个接触阶段共用一张身体，不能称为9张新身体帧。

SE接触采用imagegen新绘上身，显式蒙版保护原准备姿势的支撑下肢，并保留新前手与棍从前方遮住腿的关系。NE的0/3/4/5原稿被身体遮住的前后两段棍不共轴，已由imagegen去除旧后杆、补衣边，再把imagegen独立绘制的后杆部件按前杆中轴刚体对齐，放在身体背后；1/2完整举棍帧未做此处理。没有机械变形人物肢体。

来源及每张图的实际用途在[source/provenance.json](source/provenance.json)，完整生成提示词同目录。原生PNG以无损WebP归档，独立核对覆盖含透明区域RGB的完整RGBA。准备参数、区域蒙版、后杆层和中间表均保留，最终交付从仓库源可重建：

```sh
python3 godot-demo/art/candidates/diagonal_pixel_attack_v1/monk/rebuild.py
```

需要Python、Pillow、NumPy，公共编码工具复用本包tools/build_attack.py。原工具缓存不是重建依赖。完整公共四向菱格对照见[审阅页](../review.html)。

本包仅攻击候选。离线逐帧、相邻姿势、方向和文件检查不代表负责人已认可连续观感，也不代替Godot内攻击距离、命中同步、遮挡、状态切换验收；没有接入运行程序或新增受击动作。SE/NE表现同一方向意图，但不是通过三维投影计算得出的精确30°几何。
