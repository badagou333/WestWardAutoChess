## 调整

| 项目 | v1 | v2 |
| --- | --- | --- |
| 身体帧顺序 | 0→1→2→3→4→5→0 | 0→2→3→4→5→0，跳过1 |
| 蓄力停留 | 160ms | 200ms |
| 出手中间段 | 140ms | 30ms |

人物仍为竖棍蓄力→右上斜出→回收，不重新绘制角色、不旋转或拉伸身体帧。新版使用5个既有身体姿势，残影显隐产生多个合成阶段，不把这些阶段称作新增肢体帧。

## 残影与输出

内置imagegen仅生成[纯特效原件](source/trail_generated.png)：暖金／象牙色窄弧及淡棕棍影，三张原帧仅作几何参考。完整实发提示词见 [source/PROMPT_TRAIL.txt](source/PROMPT_TRAIL.txt)。源图有极低alpha散点，按人工显式框取主效果；完整来源、哈希与映射见 `source/provenance.json`、`impact_spec.json`。

残影画在原角色后面，三段强度为0.45／0.70／0.28，300ms即关闭。角色自身不透明像素必须与原PNG逐像素相同；FX与角色分层保存，合成RGBA允许半透明，不宣称二值alpha。GIF预留原人物颜色，只有FX新增混合色允许近似量化。

`manifest.json`／`report.json`记录时序与来源；最终独立检查见 `validation.json`。本批未运行游戏、未修改伤害／攻速、场景、production或导出配置，接触230ms只是预览事件。目录由`.gdignore`隔离。

独立峰值静态复核未见遮脸或路径必修；独立解码确认四GIF时长／共同起手准确，原角色RGB色差0，只有FX新增混色存在近似量化（最大单通道差26）。半速循环1.95秒。合成RGBA保留原始FX透明层，GIF只作审阅。

## 复现与边界

有Pillow／NumPy的Python可从任意目录运行 `build_impact.py`，按保存的 `impact_spec.json`、原版PNG和FX原件重建。

仍是独立动画候选，负责人对力量感的连续体验与游戏内命中同步待后续。原版的轻微握位／投影和前腿弓步差异未借本次特效宣称解决；本轮不扩大到新动作或运行接入。
