## 去背方法

1. 每帧单独估计背景色：取边缘条带的中位数，避开左上角“AI生成”标识（标识区 `[0,0,200,100)` 强制透明）。末帧 83 背景偏亮，为 (245,238,238)，所以背景按帧估计。
2. 按与背景色的距离，在 5～22 之间线性生成软 alpha；距离超过 22 的连通块（≥50 像素）算主体。
3. 法杖绿晶和光球的白热中心接近背景色，会被抠成空洞。对主体包住的孔洞中偏亮或偏绿的部分恢复为不透明，其余孔洞（例如杖和身体之间的真实背景）保持软 alpha。
4. 离主体较远的淡光晕先做 σ=2 平滑，非绿色的杂点清零；离主体 60 像素以外只保留绿色光晕。
5. 半透明像素做反混合，去掉背景色成分。贴着轮廓 3 像素内的半透明像素改用最近主体像素的颜色，减轻浅底白边；绿色光晕不做这一步。

浅色衣袖、白花、绿晶、法杖和烘焙在帧里的光球、光点都保留，没有重绘或调色。
