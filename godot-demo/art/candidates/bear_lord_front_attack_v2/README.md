脚锚先按首帧支撑区域估计，再用**同一原第16帧**与现运行资源配准，避免把裁后首帧和旧源第1帧的真实运动误当偏移。局部平移搜索残差为(0,0.125)输出像素，见 [registration.json](review/registration.json)。这是作者配准诊断，不是两套RGB完全相同或所有帧脚底都固定在地面。

所有帧只使用同一变换，没有逐帧锁脚、紧裁、拉伸或改变身高。原运动保留；同一世界脚点建议仍为(720,441)。棋盘离线预览仅复用现有林间底图，散列在 [qa.json](review/qa.json) 中；没有制作新棋盘。

新42～48帧脚部的灰弧覆盖采用重新标注的局部区域：保护弱对比脚轮廓，并有限估计灰雾混色。新45帧武器下方一个独立挥击碎点在源矩形`[920,480,950,515]`中去除。细节都在 [build.py](build.py) 中，不改肩甲或身体内部颜色。每帧验证深层上半身（源y<530）的原RGB保留；轮廓窄带的去污染和透明度变化单列，不以此断言所有银甲边缘逐像素不变。

依赖Python 3、NumPy、Pillow、SciPy、FFmpeg 7.1（本次验证版本；须有showinfo duration输出）。本次使用Python 3.12、NumPy 2.5.4、Pillow 13.0.0、SciPy 1.18.1。不依赖API、付费生成服务或外部源缓存。

```sh
python3 build.py --ffmpeg /path/to/ffmpeg
# 独立复建：自动从同一入库MOV重新解码，不传--decoded-dir
python3 build.py --ffmpeg /path/to/ffmpeg --output /tmp/bear-front-independent
# 原帧缓存只用于制作对照页，不作为build.py的必需输入
ffmpeg -i ../bear_lord_tail_trim_20261101/forehand-head-tail-lossless.mov -map 0:v:0 -fps_mode passthrough /tmp/bear-front-raw/frame_%03d.png
python3 review.py --ffmpeg /path/to/ffmpeg --decoded-dir /tmp/bear-front-raw
```
