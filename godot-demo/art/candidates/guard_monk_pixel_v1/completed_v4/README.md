## 制作与复核

- 采用本地最新 `seedream_v3_nearest_64.png` 作为像素方向输入，以旧README记载为负责人提供的 `source_reference.webp` 为身份参考。输入原样快照和哈希见 `inputs/`、`source/provenance.json`。其他Seedream命名试稿的生成参数未记录，本轮没有调用该服务。
- 使用**内置imagegen**精修一次，再因64px下眼鼻/念珠拥挤做唯一一次简化。首轮不采用，保存于 `history/detail_pass_generated.png`；两份完整实发提示词在 `source/`。
- 工具实际返回1254×1254，**不是原生64×64像素稿**。从保存原件只做alpha阈值、包围盒裁切、最近邻取样、无抖动24色量化和透明留边；透明RGB归零。本稿不是逐格人工绘制，不把高分辨率原件作为运行贴图。
- 作者和独立视觉复核查看最终8×及浅深底1×/3×图：獾类圆耳、黑白眼斑、突出吻鼻、赭黄袍、红腰带、双腿和连续斜棍可辨；双手持棍无明确断棍/脱手，袍褶用大色块表达。最终单张站姿候选无必修。
- 念珠在64px仅可读作短段深色饰物，不能逐粒辨认；48×56细部进一步合并，仅作尺寸参考。放大预览不替代1×辨识度。

## 接口与复现

单帧，面向画面右侧的三分之四站姿，不宣称已匹配某运行相机的精确SE。左上为 `(0,0)`；`manifest.json`建议锚点按两鞋地面位置估计，仅为静态候选，不是运行或旧动画接口实测。若后续试接，需06映射脚点、尺度和朝向，使用最近邻保持纵横比。

有Pillow的Python可在任意目录执行：

```sh
python3 /path/to/guard_monk_pixel_v1/completed_v4/export_sprite.py
```

复现指从保存原件确定性重建导出，不保证重新调用模型同图。尺寸、二值透明、24色、至少3px留边、连通性与重建一致性的独立校验见 `validation.json`。
