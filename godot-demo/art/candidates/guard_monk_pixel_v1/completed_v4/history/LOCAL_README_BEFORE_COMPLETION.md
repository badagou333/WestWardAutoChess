## 像素密度参考（负责人提供的单位截图）

- 参考图 150×142，横向色块长度集中在 2/4/6/8 → 每个美术像素约等于画面 2px，逻辑画面约 75×71。
- 单位本体（不含地格与阴影）约 **35×47 美术像素**，画布推测为 48×56 或 48×64。
- 该图经过缩放与有损压缩，原始网格无法 100% 还原，以上为估计值。
- 按此密度自动转换的 48/56 版本，长棍会断线、脸部与袍摆细节依赖压缩后的色块，不能达到参考图那种手绘像素的干净度。

## 做法

1. 四边漫水填充去掉连通白底，保留袍内/绑带的白色；
2. 按 alpha 裁到角色包围盒；
3. 预乘 alpha 后 Lanczos 缩到目标高度，避免白边光晕；
4. 中位切分量化到 32 色（无抖动），alpha 二值化；
5. 最近邻放大 4 倍出预览；方形版把角色底部居中。

复现：

```bash
python3 convert_pixel.py --height 128 --colors 32 --square --out pixel_128_square.png --preview preview_128_square_x4.png
```

## 已知限制

- 这是**程序化降采样＋限色**，不是逐格手工像素画：绑带、念珠、鞋底等细节在 128 下被简化，96 下长棍会细到 1px。
- 只有单张站姿，没有朝向、移动、攻击、受击或退场帧；**不能直接替换现有 13 帧动画**。
- 未接入 `art/runtime/`、未改场景/代码/导出配置；本目录带 `.gdignore`，不会进 Godot 导入或默认 PCK。
