## 修改与来源

原参考为负责人新出棍图的左手局部，保存在 `inputs/owner_hand_reference.png`。两张目标均从原448²身体图裁出 `[185,235,273,323]` 的88²区域，最近邻放大8倍作为输入，参考仅用于包握和掌指关系。内置imagegen分别编辑两张手部裁图，完整实发提示词在 `source/PROMPT_ACCELERATE_HAND.txt`、`source/PROMPT_CONTACT_HAND.txt`。

采用生成原件按最近邻归一回88²，再限到原96色色板、二值alpha，仅贴回 `hands_spec.json` 指定的手部多边形。加速／接触分别改变1891／1343个RGBA像素，掩码外完全保持，未镜像整手或整个人。源图、输入快照、掩码、补丁与哈希记录见 `source/provenance.json`、`patch_report.json`。

两张透明身体图在 `body/`，更新后8个合成阶段在 `render_frames/`。只改变阶段1／2／3／4，阶段0／5／6／7逐像素等于v3；接触帧远端棍段 `x≥300` 也与v3完全相同，保持末端下压。FX直接复用v2拟合图，230ms接触、800ms动作＋350ms停顿、200～300ms残影和强度均不变。

## 复核与限制

作者与独立视觉复核查看完整448px帧及放大对照：加速帧已减弱拳背朝镜头的读法；接触帧的掌根、拇指侧与腕口形成更清楚的棍下承托，贴近原参考。未见明确空握、断棍、腕口开缝或贴回浮边。浅色内侧保留参考已有的腕内侧／拇指形，不将整掌改成人类肤色。

独立结构与局部保护、全部GIF解码／时序／图集／角色色检查详见 `validation.json`；此轮手部有限视觉通过，不等于负责人最终认可、全部手指精细解剖、连续播放或游戏接入已验。旧握位投影／弓步等未验边界继续保留。

整个目录由`.gdignore`隔离，未改游戏、production、伤害／攻速或导出。旧版本原样保留，v3的“左手待修”是本次已处理的历史问题。
