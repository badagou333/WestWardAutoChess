## 相邻姿势与时序

| 过渡 | 作者核对 |
| --- | --- |
| 准备→抬翼，0～160ms | 一翼从下垂举起蓄势，上体随动、双爪留地；没有把整张站姿旋转当抬翼。 |
| 抬翼→横翼，160～280ms | 羽扇折转到胸前，肩根保有连接；另一翼承担平衡，羽扇不会变成人手。 |
| 横翼→展开释放，280～370ms | 近侧翼从胸前外张，两翼展开构成放出转折，90ms快速段可读；喙／脸仍可认，身体中没有凭空新增羽翼。 |
| 释放与飞刃，370～450ms | 370／390／410／430ms各只有同一枚风刃的一处显式位置，向右移动后出屏，450ms无层；未用多枚刃同时显现假装残影。风刃在身体后层，峰值未盖掉翼根或脸。 |
| 展开→收势，450～490ms | 无刃身体留出一次干净放出读段，再进入下扫收势；没有离屏后仍挂在翼尖的旧刃。 |
| 收势→回翼→准备，490～850ms | 两翼自然回落，披肩／羽扇有折回关系；双爪保持登记后的支撑位置，不以贴地横移表现回位。 |

## 本批失败与修正

1. 首稿蓄力／展开时站距显著变宽，直接播放会读成贴地滑爪；未采用首稿。
2. 首稿收势翼下的灰小片容易误读为多余手指；定向清除，最终仅有双翼与两鸟爪。
3. 第一次站距修正中释放左翼触到源图左边缘；再次折入完整翼尖，采用图与最终帧均未裁翼。
4. 最终源绘爪距仍有小差，利用原绘脚／踝像素登记到统一足距，蒙版外源RGBA保持；没有整体平移／缩放角色。完整单帧复核未见登记导致的断踝、旧脚或多脚。

## 技术与未验边界

- 6个不同RGBA身体、统一0.65源尺度、96身体色、二值alpha；每身体显式bbox／seed提取，源组件未被裁开，输出边界透明。
- 单帧与图集逐RGBA一致；正常／半速GIF逐时刻的身体和空白底色RGB完全保留，FX近似混色最大单通道差17。
- 风刃源为一个连通新月，四位置每时刻至多一层；后段屏边只截投射物，不截身体。采用原件无损WebP与RGBA哈希证明见`source/provenance.json`。
- 低位爪点实际观测稳定在后爪x144～145／y399、前爪x227～228／y398～400；像素重采样差约1px，不宣称运行接地或逐羽体积守恒。
- 单枚风刃沿当前Demo占位，不是新玩法确认。只攻击；无游戏事件、伤害、正式相机、其他动作或方向接入。
