## 每个角色必须核对

1. 与最新认可造型一致，视角／比例／头脸／衣装／道具稳定。
2. 每一真实姿势的手掌／拇指／腕口、脚或四足支撑、武器／弓弦／索线／翼根／尾根都明确，无多肢、反手、断物或裁残。
3. 蓄力、加速、接触或释放、回收构成一套该角色自己的动作；不能只平移／旋转整张站姿。
4. 相邻姿势的握位、武器长度、脚步落地、重心和回位自然；技术锚点相等不证明鞋爪没滑。
5. 正常与半速成品、逐帧接触表及完整解码／时序／透明边缘检查齐全；首尾闭环、投射物与角色分层关系清楚。
6. 作者与独立检查记录具体每帧结论，必修关闭后才标本批通过；负责人最终体验与运行命中验收分别保留。

源图／提示词／显式取样与重建保留。为减少新增素材体积，可用**像素完全一致的无损WebP**保存新生成源图，记录原PNG文件hash和解码RGBA hash，逐像素验证；不损失画质，不改旧Git历史或已存在原件。
