## 已检查的实际姿势

所有7张`frames/*.png`均查看完整448px单帧；另查看全部12时刻接触表及必要3倍手/箭细节。

| 身体帧 | 检查内容与作者结论 |
| --- | --- |
| 00_ready | 斗笠/棕白兽脸/绿衣/环纹尾锁身份；双手各握弓与现有单箭，双靴完整。起终使用此同一张，不另生相似末帧。 |
| 01_nock | 低位搭箭，后手/箭尾接近弦的V汇合点；前手仍握弓中心，箭过其上。原短箭已只修箭身/箭头，未见双箭头、断轴或显著贴回开缝。 |
| 02_full_draw | 前臂伸弓、后手至脸侧，单箭指右；上/下弦腿接同一拉弦点，弓臂与两端连接可辨。没有保留另一条直弦形成双弦。 |
| 03_release | 后手离弦随动、弦回到弓侧；身体本身无待发箭。飞箭单独后层，未在掌内残留一支箭又额外发一支。指部释放幅度较小，以离弦关系与手位置表达，不称精细逐指动画。 |
| 04_reach_quiver | 后手伸至背后箭袋，手中尚无突然出现的替换箭；前手继续持同一弓，双耳/斗笠/靴未裁残。 |
| 05_extract_arrow | 已显露一支整箭横在帽上，连续轴/箭羽/箭头齐全，后手抓箭身。不是原失败稿的一把羽簇。 |
| 06_lower_arrow | 后手将刚取的箭放低到腰前，前手放低弓；身份/道具不换。脚与尾为源姿势中的站姿变化，不宣称全程双脚锁死。 |

## 相邻与时序

| 过渡 | 作者检查结论 |
| --- | --- |
| ready→nock | 原先持有的箭被移向弓，不是新增箭。身体真实变化，不以整张平移假装搭箭。 |
| nock→full_draw | 低位搭箭抬至瞄准，前后臂分工保持；短箭修后两阶段箭长处于同量级。省去不合格半拉帧，跨幅较大，留独立重点核自然度。 |
| full_draw→release | 放箭在580ms开始，以单独箭层接续；后手离弦，弓继续由前手握住。 |
| release的四飞箭位置→无箭 | 箭沿一条水平线向右飞出，修后箭羽不再是初版大白扇；80ms内退出，后续不挂箭影。 |
| release→reach→extract | 先伸手、再见完整一箭，明确来自箭袋。未添加新武器、魔法、宠物或受击。 |
| extract→lower→ready | 同一替换箭逐步回腰前，首尾回同ready图；不因首尾相同声称中间全无形体漂移。 |

正常1760ms、半速3220ms两份实际GIF已全解码，按阶段先后和编码毫秒边界核读全部姿势/箭层。记录在`playback_review.json`；这是顺序选帧及实际时序复核，不是OS实时录屏或真人连续观感。

## 失败与必要修正记录

1. 首轮搭箭被画成提前瞄准，箭尾扣弦不清；半拉弓箭长随拉距变化，抽箭只见羽尾。本轮不放行首稿。
2. 第一轮只改搭箭与抽箭：得到完整单箭抽取，低位搭箭恢复；搭箭的弦点仍不够明确，再只修其弦/箭/手接触。
3. 修后sheet用于7姿势，右上半拉格仍不采用，未伪装成合格过渡。
4. 首次引擎成品显示独立飞箭箭羽过大，另做只含一支箭的定向原件，改为200×15px飞箭，身体不因此重新生成。
5. 搭箭箭身偏短，使用imagegen单帧箭部改稿；仅小掩码贴回箭身/箭头，保留其余原源，消除旧箭头/新箭头并存与长度跳变。未把改稿整身替换源角色。

源原件用无损WebP exact保存并逐RGBA验证；未采用整张原件仅保留hash/原因，不重复囤PNG。所有创作改稿通过内置imagegen，准备脚本只作注册、取样和分层。
