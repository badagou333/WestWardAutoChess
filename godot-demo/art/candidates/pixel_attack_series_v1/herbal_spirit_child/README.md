## 取样、接地与杖环

身体统一448²画布、0.65源尺度、96身体色、二值alpha。逐姿势显式bbox＋seed提取，不平均切格，不按每帧身高拟合。共同支点是杖底`(100,400)`。

源图上下留白较窄，但alpha≥128的主体均未触及全图四边；取用的是完整轮廓。包装后每张身体距离画布边缘至少47px。透明背景中的隐藏RGB不作为不透明背景处理。

准备工具只对原绘脚／踝作小幅局部注册，把两个鞋底与杖底落到同一地面；施法手、脸和整身体型没有被机械挤压或整体平移。圈杖上环是刚性物件，统一复用源pose0同一绘制部件并相对杖底注册，保持圆环尺度。来源区域与位移详见 source/preparation_report.json（历史文件已清理），这些区域以外的源RGBA逐像素保持。

最终实际低位点：杖底`(100,400)`，后鞋底`(137,400)`，前鞋底`(233～234,400)`；1px横向差属于采样，不作为运行接地证明。作者已逐张检查鞋踝接续、手掌／腕口、持杖关系和杖环，没有只凭这些数值放行。
