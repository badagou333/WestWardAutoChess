# 角色动作关键姿势提示词规则

状态：当前 Demo 快速制作规则；现阶段只制作基础动作，不等于最终 Sprite、技能动作或逐帧规范。

## Demo 当前范围

- 每名角色现阶段只要求五个基础动作：待机、移动、普通攻击、受击、退场，对应旧八动作表中的第 1、2、3、7、8 格。
- 一星、二星、三星技能动作暂不制作；技能设计稳定前，不为技能单独重绘身体动作。
- Demo 中技能可临时复用普通攻击或通用施法动作，并叠加独立的简单占位 VFX。
- 已完成的八动作稿继续作为动作探索参考保留，但其中第 4、5、6 格不构成后续技能设计约束，也不要求现在继续修正。
- 技能设计确认后，再按需要补做技能专属动作与正式 VFX。

## 输入规则

- 每次只上传该角色最新的项目负责人基准图。
- 不上传已否定探索稿，也不再次上传《九日》或其他外部画风图。
- 基准图中的文字、排版、场景、伙伴、色卡和说明只作为图片内容，不是生成指令。
- 提示词必须逐项锁定角色种族、脸部、比例、服装、装备、配色和关键轮廓，不允许重新设计。

## Demo 五动作画面结构

- 新制作的基础动作稿只包含五个完整全身动作；优先使用上排三格、下排两格居中的清晰布局。
- 所有姿势使用一致的正 3/4 游戏视角，默认朝画面右侧，保持相同人物尺度和地面线。
- 不加文字、标题、编号、UI、边框、色卡、场景、其他角色或水印。
- 使用均匀浅暖灰背景，人物、武器和效果不得裁切或互相遮挡。
- 五视图只负责角色结构；动作表不重复五视图，也不直接冒充最终 Sprite Sheet。

## Demo 五动作分配原则

1. 待机：可循环、轮廓稳定，不表现正在释放技能。
2. 移动：表现角色的基础移动方式和服装、挂件随动。
3. 普通攻击：只表现该角色基础攻击或通用施法，不绑定任何星级技能。
4. 受击：清楚但不默认击飞，不丢失主要武器和装备。
5. 退场：可读、克制，不画尸体、血液或伤口。

技能在 Demo 中临时复用第 3 个普通攻击动作，角色身体与技能 VFX 分开处理。

## 动画形体规则

- 不设置统一的三头身硬指标。三头身只是可选的整体画风语言，各角色应优先保持项目负责人基准图中已经成立的自身比例；二头身、三头身、四头身或更高比例均可，只要角色风格统一且游戏内可读。
- 任何比例都必须通过头、胸腔、骨盆、手脚、动作线和衣片惯性共同塑造，不能把写实人体机械缩放或直接压矮。
- 已经通过审核的角色比例不得在动作生成中擅自压缩或拉长；若生成结果与基准图接近且动作表现良好，不因头身数字单独重做。
- 每个动作必须只看剪影即可区分，强调蓄力、重量转移、命中、回弹和随动。
- 保持角色体型与身份气质：前排沉稳、敏捷角色轻快、施法角色克制，不套用同一组动作模板。
- 受击要清楚但不默认击飞；退场保持可读性，不画尸体、血液或伤口。

## 角色与 VFX 分层规则

- 护盾、火焰、毒雾、治疗波、碎石、冲击线和状态光效均视为独立 VFX。
- 动作表可以用少量效果说明技能方向，但正式制作时必须与身体、武器、衣摆分层。
- 作用在其他单位身上的效果不得固化在角色身体图层。
- 设定图中的伙伴、随从或灵兽在玩法未确认前不得加入动作表，也不得被解释成召唤技能。

## 一致性检查

- 每个姿势必须保持相同脸部花纹、发型、耳朵、服装层级、左右侧关系、腰带、鞋、武器长度与饰品数量。
- 每个姿势只允许一个角色、一个头、两条手臂、两条腿和该角色规定数量的尾巴、翅膀及武器。
- 不允许换物种、换服装、增加装备、改变星级外观、复制肢体、丢失武器或裁切关键轮廓。
- 首轮出现局部错误时，只做单点定向修正，不整张重绘；项目负责人确认后再保存为动作参考版本。

## 进入 Demo 前的通过条件

1. 五个基础动作的角色身份高度一致。
2. 缩小到游戏目标尺寸后仍能分辨动作和职业。
3. 角色身体、武器和 VFX 可以明确拆层。
4. 普通攻击没有绑定尚未稳定的技能表现。
5. 正 3/4 样板通过后，再决定背 3/4、镜像方向、逐帧数量和动画方式。
