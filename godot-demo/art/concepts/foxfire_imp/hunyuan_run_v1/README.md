# 狐火小妖：原地奔跑骨骼动画候选 v1

日期：2026-10-13。负责人本轮要求查看骨骼并制作奔跑动作。仅制作本角色独立小样，不改游戏，不代表全员三维迁移或正式动画验收。

## 在 Blender 中查看和播放

1. 先保存自己已打开的其他工程。在 Blender 用「文件 → 打开」选择本目录 `foxfire-run.blend`，不是「导入」旧的 `source.glb`。
2. 工程已选中 `Foxfire_Rig`，处于「姿态模式」，并开启骨架「在前面显示」和视口叠加层。身体里面的骨骼应能直接看到；尾巴有独立五节骨链。
3. 鼠标放在三维视口或时间轴，按空格播放/停止。时间轴 1～24 帧是完整一轮；可拖动时间轴慢慢看。
4. 如果自己关闭过显示：右上物体列表选 `Foxfire_Rig`，切「姿态模式」；开启三维视口顶部的叠加层按钮，在对象属性的「视图显示」中勾选「在前面显示」。检查物体列表中骨架未隐藏。
5. 想只看模型，临时关闭叠加层即可；这不会删除骨架。手动摆姿势可先暂停并另存副本，再选骨骼按 `R` 旋转；本小样没有可拖脚的 IK 控制器。

下载的原始 `source.glb` 没有骨骼。打开那个文件看不到骨骼是正常的，必须打开上述新工程或导入本目录带骨骼的 GLB。

## 交付

- `foxfire-run.blend`：可编辑骨架、权重、奔跑关键帧，原贴图内嵌；附不导出的灯光/相机/地面。
- `foxfire-run.glb`：人物网格、25 根骨骼及单个 `Foxfire_Run_InPlace_v1` 动画，无地面/相机/灯。
- `run-front.gif`、`run-side.gif`：实际 Blender 蒙皮渲染，固定前侧/侧面相机；不是二维图片扭动。
- `run-front-poses.jpg`、`run-side-poses.jpg`：八时刻检查图。
- `build_run.py`、`check_export.py`、`encode_preview.py`：可复现制作、GLB 重新导入验证和预览编码；报告记录实际检查范围。

## 动作和边界

30 FPS，24 个唯一帧，0.8 秒一轮；导出的第 25 帧复制第 1 帧作为循环端点，Blender 播放区间 1～24 避免多停一帧。动作包含交替落地/蹬地、屈膝回收、短暂双脚腾空、反向摆臂、躯干起伏与五节尾链摆动。

这是**原地奔跑**：角色根节点没有水平前进，之后由程序控制角色实际移动与动作速度。腿部位置通过两段骨骼几何计算后烘焙为普通旋转关键帧；不是导出实时 IK 约束，不依赖付费插件。周期、步幅均为本小样提案，不是新玩法移速定案。

源静态模型及 `hunyuan_rig_v1/` 保持不变。本目录可以为跑姿局部调整蒙皮，不覆盖旧绑定。衣袖/袍摆没有布料模拟，手爪没有独立手指骨，表情、完整碰撞、游戏引擎导入和性能尚未验收。首尾位置闭合不等于所有顶点速度连续，也不等于最终视觉质量通过。

## 复现

保留与 `../hunyuan_rig_v1/` 的相对目录关系，安装 Blender（其内置 Python 含 NumPy），另以有 Pillow 的 Python 编码 GIF：

```sh
blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python build_run.py -- --render
blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python check_export.py
python3 encode_preview.py
```

只重新渲染已保存工程可用 `build_run.py -- --preview-only`，不重新生成或保存绑定。`preview_frames/` 是可再生的中间帧，不进入 Git；工程、GLB、两 GIF、检查图、说明和脚本纳入本批。`.gdignore` 隔离游戏导入。
