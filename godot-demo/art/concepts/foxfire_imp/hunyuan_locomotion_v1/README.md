# 狐火短步跑 / 起停修正候选

2026-10-13 · 05美术。负责人认为旧移动不自然，授权本轮优化；不代表正式战斗接入或新版已经获用户认可。

## 本轮改变

- 在原25骨、网格、权重、UV、贴图不变的前提下重做移动腿部。原Kenney CC0重定向动作保留；新动作借用收敛后的躯干/尾部旋转，双脚通过分段支撑轨迹与两骨IK重新求姿，不再保留原大幅腾空跨步。
- `NaturalRun`：0.6秒、72段120Hz采样、每周期0.8模型单位；每腿40%支撑相、交替摆腿，足底摆动最高约0.088模型单位，骨盆起伏范围从旧约0.059降至0.018。保持两腿小跑，不是火女式悬浮，也不是普通慢步行。
- 一手一火、高低双手和旧待机/左右攻击保持。新低骨盆曾使尾尖穿地，已只抬新Run尾根12度修复；原动作不改。
- 独立棋盘保持2.35世界单位/秒速度上限、角色缩放1.65；名义动作速度2.2，实际步频按实际移动速度/2.2变化。加入短加减速、转角前减速和低速回站姿，直线跨格不重播步相。
- 低速姿势混合及停步crossfade均有足底高度修正：仅上抬显示根骨，不改角色逻辑位置。`sole_probes`来自原全权重足底凸支撑点，不是脚骨尖替代。满速原姿势、攻击、暂停时不额外累计补偿。

## 文件与重建

- `build_locomotion.py`：Blender制作/导出。读取既有 `../hunyuan_board_actor_v1/foxfire-board-actor.blend`，不另提交完整模型。
- `locomotion-animations.json`：glTF父节点局部完整TRS、25骨75轨、接地探针；运行副本在独立试场 `assets/`，需字节一致。
- `build-report.json`：制作端73姿势、循环与原动作签名、足底轨迹对照。近地滑移口径包括抬脚/落脚边缘，不能误称零滑步。
- `verify_skinning.py` / `independent-skinning-report.json`：不依赖Blender的独立完整GLB蒙皮检查，Python＋NumPy可重跑。9档混合权重×121时刻，共1089姿势；完整40,310顶点，包含整足而不只底面样本。`--no-grounding`负对照会真实失败退出。

制作命令（Blender可执行路径按本机调整）：

```sh
blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python build_locomotion.py
python3 verify_skinning.py
```

制作脚本可加 `--render` 输出本地正侧门审图，`--save-preview` 在Mac临时目录保存带新动作的预览工程。中间GLB、Blender工程和PNG忽略提交；跨机器试玩只依赖仓库内轻量JSON与原模型。

## 验证边界

- 修复顺序保留事实：首轮尾尖穿地；第二轮低速插值穿脚；最后发现停步0.12秒混合穿脚。均修复后重新检查，不能把首轮程序通过当视觉通过。
- 独立1089姿势最终无脚、尾或全网格穿地：整足最低约0.001879模型单位，按实际石面Y=-0.002计有约0.00510世界单位余量；最大根补偿0.024173模型单位。探针对真实最低点最大高估0.000121，非精确接触求解。
- 支撑相独立121采样的固定足底顶点滑移均值约0.162%移速，近地边缘口径约5.08%、最大50.50%。后者包含脚已开始离地的边缘，不以更漂亮口径掩盖残余滑移。首末位置闭合，接缝速度仍非严格C1。
- 新程序移动120项、原逻辑13项、攻击43项及视口输入17项记录在[独立试场](../../../reviews/foxfire-3d-board-v1/README.md)。实际试场运行负责起停/转弯，并非将这份单循环JSON导入任意程序就自动完成上述控制。
- 宽袖、裤腿、袍摆和尾巴仍属简化蒙皮；没有布料模拟、脚趾滚动骨或逐足转身动画。脚底位置采样不证明衣物无自交，数值通过也不代替真人连续体验。正式Demo/其他角色/战斗规则未改。
