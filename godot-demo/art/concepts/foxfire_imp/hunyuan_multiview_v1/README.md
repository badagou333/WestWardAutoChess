## 官方要求与制作建议分开

- [腾讯混元专业版官方接口](https://intl.cloud.tencent.com/zh/document/product/1284/75540)：正面主图配left/right/back附图，每个视角一张；附图JPG/PNG，单边大于128、小于5000，编码后不超过8MB。本套统一PNG、编码估计约2.10～2.16MB/张，符合所查接口尺寸/格式/体积条件。
- [腾讯云MPS多图指南](https://intl.cloud.tencent.com/zh/document/product/1041/83398)：另一入口支持2～8张且包含front，不重复视角。支持八张不等于必须生成八张，当前先交四基础视图。
- 没有实际核实负责人当前混元网页的全部上传限制；API条件不冒称网页硬限制，以当前网页提示为准。单角色、同姿态/服饰/配色、白底/均匀光照是本套为减少重建矛盾采用的制作规范，不标为官网全部强制要求。

## 检查与限制

四张分别经主代理原生输出查看及独立只读视觉复核，单角色/单尾、正侧背、后脑无正面脸、居中后伸尾巴成立，无本轮必修。背面后耳/脚跟已按真实后视表面生成；未复制前腰铃到背面。耳高、尾尖、手爪、衣褶有小幅漂移，侧面仍有少量透视。以亮度阈值估计主体高度：正0.798、左0.860、右0.888、背0.845；全部未触外边界。这不是严格尺度锁定的真实3D转盘，也不能保证多图一定比单图生成更好。

本套可用于混元重建试验，不是最终角色或运行资产。生成后检查尾根是否在后中线、是否只有一尾、宽袖/衣摆粘连和背面细节，再决定减面/绑定；输入图本身不会自动补骨骼、权重或制作游戏动画。没有代用户上传混元、调用云API、订阅或修改原Tripo模型/旧二维素材/游戏程序。
