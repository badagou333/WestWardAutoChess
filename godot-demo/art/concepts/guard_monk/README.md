## v1 状态

- 项目负责人已明确表示对这一版整体感觉不满意，本稿未通过角色方向确认。
- 文件保留用于说明需要避免的方向，不应作为后续三视图、动画、身体分层或其他角色的造型基准。
- 这是用于回顾角色比例、轮廓、配色和动画拆分问题的探索稿，不是最终游戏贴图。
- 角色采用约三头身的成年人比例，保持宽肩、短腿和较大的手脚，方便缩小后辨认。
- 一星造型刻意保持朴素：深青灰无袖外袍、土黄色内衫、绑带、布鞋、暗红木念珠和无环木棍。
- 木棍没有九环结构，避免与唐僧的锡杖混淆。
- 图片为带纯浅暖灰背景的 RGB PNG，不是真透明图，也没有完成身体部件分层。

## 进入正式动画前仍需完成

1. 在实际 5×7 棋盘尺寸下测试正面与侧面轮廓。
2. 确认脸型、年龄感、服装细节和色板。
3. 绘制真正一致的动画标准三视图，并拆分头、躯干、四肢、衣摆和武器图层。
4. 制作待机、移动、普攻、横棍护法、震地棍、受击和死亡动画。
5. 设计二星和三星的外观增量。

当前先使用 `PROMPT_ACTION_SHEET_V1.md` 生成动作关键姿势表，验证同一角色在待机、移动、普攻、护盾、震地、受击和退场中的一致性与重量感；关键姿势通过后再制作逐帧或骨骼动画。

项目负责人已提供并要求保存 `guard_monk_action_keypose_sheet_v1.png`。该图的八个姿势可作为当前动作设计参考；进入逐帧制作时仍需统一佛珠、衣摆破损、袖口缠布和禅棍长度，把护盾与震地碎石拆成独立特效层，并适当收紧受击后仰幅度。

此前“退回角色轮廓探索、不以探索图作为参考”的要求只适用于项目负责人基准图出现之前；当前后续工作必须以 `guard_monk_project_owner_reference_v1.png` 为唯一角色造型输入，仍不得使用助手探索图作为基准。
