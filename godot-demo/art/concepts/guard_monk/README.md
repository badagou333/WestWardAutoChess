## v1 状态

- 项目负责人已明确表示对这一版整体感觉不满意，本稿未通过角色方向确认。
- 文件保留用于说明需要避免的方向，不应作为后续三视图、动画、身体分层或其他角色的造型基准。
- 这是用于回顾角色比例、轮廓、配色和动画拆分问题的探索稿，不是最终游戏贴图。
- 角色采用约三头身的成年人比例，保持宽肩、短腿和较大的手脚，方便缩小后辨认。
- 一星造型刻意保持朴素：深青灰无袖外袍、土黄色内衫、绑带、布鞋、暗红木念珠和无环木棍。
- 木棍没有九环结构，避免与唐僧的锡杖混淆。
- 图片为带纯浅暖灰背景的 RGB PNG，不是真透明图，也没有完成身体部件分层。

## 进入正式动画前仍需完成

1. 在实际 5×7 棋盘尺寸下测试正面与侧面轮廓。
2. 确认脸型、年龄感、服装细节和色板。
3. 绘制真正一致的动画标准三视图，并拆分头、躯干、四肢、衣摆和武器图层。
4. 制作待机、移动、普攻、横棍护法、震地棍、受击和死亡动画。
5. 设计二星和三星的外观增量。

下一轮应退回角色轮廓探索阶段，从空白设计多个差异明显的小稿；不以本图作为造型和风格参考。新方向确认前，不应批量生产其他角色。
