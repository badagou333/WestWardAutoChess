# 护寺棍僧探索稿 v1

## 文件

- `guard_monk_model_sheet_exploration_v1.png`：一星护寺棍僧的正面、侧面、背面、战斗姿态、武器和色板探索稿。
- `PROMPT.md`：生成修正版设定稿时使用的提示词与参考图角色说明。

## 当前状态

- 这是用于验证角色比例、轮廓、配色和动画拆分方式的探索稿，不是最终游戏贴图。
- 角色采用约三头身的成年人比例，保持宽肩、短腿和较大的手脚，方便缩小后辨认。
- 一星造型刻意保持朴素：深青灰无袖外袍、土黄色内衫、绑带、布鞋、暗红木念珠和无环木棍。
- 木棍没有九环结构，避免与唐僧的锡杖混淆。
- 图片为带纯浅暖灰背景的 RGB PNG，不是真透明图，也没有完成身体部件分层。

## 进入正式动画前仍需完成

1. 在实际 5×7 棋盘尺寸下测试正面与侧面轮廓。
2. 确认脸型、年龄感、服装细节和色板。
3. 绘制真正一致的动画标准三视图，并拆分头、躯干、四肢、衣摆和武器图层。
4. 制作待机、移动、普攻、横棍护法、震地棍、受击和死亡动画。
5. 设计二星和三星的外观增量。

在项目负责人确认之前，不应以本图为基础批量生产其他角色。
