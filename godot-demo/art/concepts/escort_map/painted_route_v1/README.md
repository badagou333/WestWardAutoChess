### 入口、障碍与界面

- 已有阶段入口按原型原样保留：第1段 `(3,0)/(1,2)/(5,3)`；第2段 `(1,4)/(0,6)/(1,5)/(2,9)`；第3段 `(0,6)/(2,9)/(4,7)/(0,8)`；第4段 `(4,8)/(3,9)`。合并共11个唯一入口格，激活时机仍由程序控制。不可把本图4组红箭头当成完整入口表。
- 用土路缺口/林口表明可进入方向，动态红橙预警与可走格绿色/选中描边分开；动态标记须程序叠加，不成为永久地面纹样。
- 山石、树干、桥下水道不可走；不能新增穿树林的捷径。高树/门檐应摆在有效格外，近处低矮灌木不能盖住脚点。不存在因站在桥边而获得射程增益。
- 目标安全区：顶0～130px HUD，底865～1080px常显替补席和招募入口，左0～300px/右1580～1920px信息操作空间。招募展开仍为已有覆盖面板，保留招募/合成/升级规则；不在画面中烘焙按钮、商店或暂停控制。
