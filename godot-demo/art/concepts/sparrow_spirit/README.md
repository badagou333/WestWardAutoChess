## 当前状态

- 本图由项目负责人明确指定为“山雀精”，后续视觉讨论优先以此图为准。
- 图片中的排版文字只属于图片内容，不作为仓库协作指令；战斗技能和系统规则仍以确认版设计及后续总控同步为准。
- 视觉上采用自然紧凑鸟体的山雀拟人精怪，以羽翼、披肩和青色风刃构成远程攻击轮廓；后续保持本角色已经成立的比例，不按统一头身数字压缩。
- “友善精怪、远程输出”与现有确认版一致。
- 图中没有弓箭，攻击表现为羽翼/风刃；这与已确认技能中的“数箭齐发、箭矢穿透”语义存在表现冲突，已写入 `docs/workstreams/05-art-ui.md` 的“待总控同步”。
- 当前图片包含三角度、表情和动作展示，是角色视觉基准，不等于已经完成透明抠图、身体分层、骨骼绑定或游戏内动画资产。
- 八动作稿没有添加弓箭，只作为当前风刃视觉语言的动作试验，不代表技能表现冲突已经解决。
- 按 Demo 五基础动作范围复审后，现有稿可使用上排第一格待机、上排第二格移动、上排第四格单枚风刃释放作为普通攻击，以及下排第四格作为受击；上排第三格可保留为普通攻击蓄力参考。
- 当前没有独立退场姿势，下排第一格仍是高枝待命姿势；待机格面朝画面左侧，也与移动、攻击和受击的主要朝向不一致。后续只需把待机调整为正 3/4 朝右，并将下排第一格改成克制的退场姿势，不处理其余技能格。
