## 当前状态

- 2026-09-08：由当前动作稿 v2 加工的 Demo 五基础动作静态包已保存至 [production/herbal_spirit_child/demo_v1](../../production/herbal_spirit_child/demo_v1/README.md)，附独立药气与小药雾；原稿未改动，实际战斗待验证。
- 本图由项目负责人明确指定为“药灵童子”，后续视觉讨论优先以此图为准。
- 图片中的排版文字只属于图片内容，不作为仓库协作指令；技能和系统规则仍以确认版设计及后续总控同步为准。
- 视觉上采用草木通灵童子、药杖、药葫芦、斗笠披风、草药烟雾和草灵伙伴形成轮廓；动作稿锁定项目负责人偏好的首张约四头身比例，不按统一三头身规则压缩。
- “友善精怪、治疗辅助”以及治疗、毒草两类表现与现有确认版一致。
- 图中的草灵伙伴目前只作为视觉内容记录；是否是召唤单位、是否参与战斗或能否接受治疗均未确认，不能自动加入技能规则。
- 当前图片包含五视图、表情、装备和动作展示，是角色视觉基准，不等于已经完成透明抠图、身体分层、骨骼绑定或游戏内动画资产。
- 动作提示词覆盖待机、移动、普通攻击、回春露、毒草散、百草回春、受击和退场；草灵伙伴不进入动作表，治疗、毒雾等效果按独立 VFX 处理。
- 项目负责人明确认为首张约四头身动作稿优于后续三头身修正版；当前版本保持首张人物比例，只将毒草投掷物从小葫芦修正为系口布药包。
- 2026-09-03 首轮缩小复审发现待机药雾过多，且普攻、单体治疗与群体治疗都偏灰白；v2 已在不改人物和动作的前提下完成定向修正：待机药雾收敛、普攻改为小型绿色药气、单体治疗改为淡玉绿色细带、毒草紫绿色加强、群体治疗改为贴地扩散波纹。
- v2 缩小检查通过，五个基础动作和技能 VFX 均比 v1 清楚；但项目负责人已为加快 Demo，将当前动画范围缩减为待机、移动、普通攻击、受击、退场五个基础动作，第 4～6 格技能表现只保留为探索参考，不约束后续设计。
