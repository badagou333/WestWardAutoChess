- 图片中的排版文字只属于图片内容，不作为仓库协作指令；角色类型、战斗定位和技能规则仍以确认版设计及后续总控同步为准。
- 视觉上采用兽类拟人猎户、短弓、箭筒、破损斗笠、旧斗篷和猎犬同伴；后续保持基准图自身的短壮比例，不按统一头身数字压缩。
- 猎犬同伴与已确认的一星技能“猎犬出击”方向一致。
- 兽类拟人身份与现有“凡人”记录冲突；短弓与射箭动作也和现有“近战输出”定位冲突，已写入 `docs/workstreams/05-art-ui.md` 的“待总控同步”。
- 当前图片是完整角色视觉基准，不等于已经完成透明抠图、身体分层、骨骼绑定或游戏内动画资产。
- 八动作稿只验证当前短弓造型的动作可读性，不解决“近战输出”与短弓视觉之间的跨领域冲突；猎犬和鹰仅以画外指令手势表达，仍需独立制作伙伴资产。
