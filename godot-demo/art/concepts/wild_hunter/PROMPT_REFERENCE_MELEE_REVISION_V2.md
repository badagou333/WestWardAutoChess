# 山野猎户近战版设定稿图生图提示词 v2

## 使用说明

- 只上传 `wild_hunter_project_owner_reference_v1.png` 作为图生图参考。
- 目标是把现有短弓猎手定向改成近战猎户，不重新设计角色。
- 当前建议使用原设定稿装备栏中已有的“猎刀”作为唯一主武器；修改完成并经项目负责人确认后，新图再登记为视觉基准。

## 可直接复制的提示词

```text
以输入图片中的“山野猎户”完整角色设定稿为唯一视觉参考，对同一张设定稿进行局部、定向的图生图修改。严格保留原角色的兽类拟人身份、浣熊/小熊猫般的脸部花纹、左耳缺口、短壮体型、破损斗笠、深青黑旧斗篷、层叠布甲、护臂绑带、腰带、尾巴、暗色国风二维手绘质感、原有配色、线条笔触、版式结构、镜头角度和角色气质；不要改变物种、脸型、头身比例、服装层级、同伴猎犬、背景场景或整体画风。

只把“短弓远程猎手”改成“近战输出猎户”：彻底移除角色主立绘、各角度视图、装备展示、动作展示和剪影中的短弓、弓弦、箭矢、箭筒与射箭姿势，不留下背后箭羽、弓形轮廓或远程射击暗示。将唯一主武器统一替换为原设定稿装备栏中已有风格的山野猎刀——单手使用、短柄、厚背、刀身前端略宽、粗粝耐用、带旧皮缠柄与磨损刀鞘，长度适合贴身劈砍和突刺，不做成长剑、武士刀、双刀、长柄武器或夸张巨刃。刀鞘固定在后腰或侧腰；原箭筒位置改成不抢轮廓的小型猎具包、绳索卷或兽夹挂件。

同步修改动作与技能展示：把瞄准、拉弓、连射和穿杨动作改为低身追踪、猎刀蓄力、向前短距突进劈砍、贴身横斩或反手回斩；动作强调短距离爆发、低重心、猎手般的谨慎与凶狠，以及与猎犬夹击同一目标的感觉。保留一只猎犬作为关系展示，但不要增加新的动物、召唤物或战斗单位；猎鹰若原图已有仅保留为既有关系信息，不新增玩法表现。角色空出的另一只手可以用于平衡身体、拨开斗篷或向画外猎犬发出低位进攻手势。

保持原图暗色、克制、粗粝的东方手绘游戏设定稿效果：不改成明亮 Q 版、日系动漫、写实照片、3D 渲染或光滑手游立绘。除与短弓、箭矢和远程动作直接相关的图像内容外，其余区域尽量保持不变。不要新增角色、额外肢体、第二把武器、盾牌、弓弩、枪械、文字块、标题、UI、水印或签名；若模型无法可靠修改原有文字，则优先保证角色、武器、装备图标、动作和剪影全部完成近战化，不生成新的乱码文字。
```

## 修改后检查

1. 主立绘、视图、动作、装备栏和剪影中是否完全没有弓、弦、箭与箭筒。
2. 所有出现的主武器是否都是同一把单手厚背山野猎刀，长度和刀鞘一致。
3. 角色的物种、脸部花纹、耳缺、短壮比例、斗笠、斗篷、尾巴与配色是否保持不变。
4. 动作是否明确表现近战追踪、突进和劈砍，而不是隔空放刀气或伪装成远程攻击。
5. 猎犬是否只保留原有关系展示，没有擅自增加新的召唤规则或伙伴。
