《西游护送》行路试炼说明（移动护送原型）

一、启动
1. 将整个 ZIP 解压到普通文件夹，不要直接在压缩包内运行。
2. 双击 JourneyEscort.exe。
3. 本包不需要安装 Godot，也不需要联网。
4. 本包尚未进行代码签名。若 Windows 显示安全提示，请先向发送者核对 ZIP 的 SHA-256；不要关闭杀毒软件或系统安全功能。

二、推荐体验流程
1. 初始有 3 金币、3 人口。按空格或点击左下按钮展开招募商店。
2. 建议先购买护寺棍僧、山雀精和药灵童子，也可自行组合。
3. 把队员放到唐僧附近绿色陆地格，避免挡住金线路线。唐僧所在格和水面不能部署。
4. 点击“出发”。唐僧沿金线从 A 前往 B；队员需要实时调动，到位后驻守并自动攻击，不会自动全场追敌。
5. 左键选队员再点空格，或拖向目标、右键下令。红色闪格预告下一只敌人入口；把前排送到入口方向，远程和治疗跟上唐僧。
6. 唐僧抵达营地且清敌后进入不限时整备，可刷新、购买、合成、出售、升级人口，再手动出发下一段。
7. 完成四段抵达 B 或失败后，可点击“重新体验”从头开始。

三、快捷操作
- 空格：展开或收起商店。
- 数字键 1—5：商店展开时购买对应角色。
- R：商店展开时刷新；每轮整备首次免费，之后每次 2 金币。
- E：升级人口。
- P 或右上“暂停/继续”：暂停或继续战斗。
- 暂停时也可指定队员移动目标，恢复后执行。唐僧右侧“暂驻/继续行进”只控制他，不暂停其他单位。
- 右上“1×/2×”：切换战斗速度。
- 右上音效开关与音量滑条：开关或调整试玩音效；暂停时声音也会冻结。
- Esc：收起商店；战中同时取消选中队员移动令并取消选择。

四、胜败与结算
- 唐僧生命归零则本轮失败，当前波战利品不结算。
- 每波胜利后，战利品按唐僧当时剩余生命结算并立即到账。
- 唐僧活着到达 B 且最后一段全部清敌才算胜利；只打完敌人但未到终点不会结算。
- 当前版本没有存档；退出或重新体验都会从 3 金币与空阵容开始。
