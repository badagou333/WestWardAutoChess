《西游护送》四波试玩说明

一、启动
1. 将整个 ZIP 解压到普通文件夹，不要直接在压缩包内运行。
2. 双击 JourneyEscort.exe。
3. 本包不需要安装 Godot，也不需要联网。
4. 本包尚未进行代码签名。若 Windows 显示安全提示，请先向发送者核对 ZIP 的 SHA-256；不要关闭杀毒软件或系统安全功能。

二、推荐体验流程
1. 初始有 3 金币、3 人口。按空格或点击左下按钮展开招募商店。
2. 推荐先购买护寺棍僧、山野猎户和药灵童子，也可自行组合。
3. 把队员拖到棋盘，或先点队员、再点格子。中央唐僧所在格不能部署。
4. 点击“开始战斗”。每波结束后会进入不限时整备，可刷新、购买、合成、出售、升级人口和调整站位，再手动开始下一波。
5. 完成四波或失败后，可点击“重新体验”从头开始。

三、快捷操作
- 空格：展开或收起商店。
- 数字键 1—5：商店展开时购买对应角色。
- R：商店展开时刷新；每轮整备首次免费，之后每次 2 金币。
- E：升级人口。
- P 或右上“暂停/继续”：暂停或继续战斗。
- 右上“1×/2×”：切换战斗速度。
- 右上音效开关与音量滑条：开关或调整试玩音效；暂停时声音也会冻结。
- Esc：收起商店。

四、胜败与结算
- 唐僧生命归零则本轮失败，当前波战利品不结算。
- 每波胜利后，战利品按唐僧当时剩余生命结算并立即到账。
- 最后一波击败熊山君后显示最终星级。
- 当前版本没有存档；退出或重新体验都会从 3 金币与空阵容开始。
