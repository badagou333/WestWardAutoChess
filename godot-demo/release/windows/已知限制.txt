已知限制（移动护送原型）

- 这是单地图四段A→B移动护送原型，不是第一章完整版本；地图为程序绘制的简化地形，数值、节奏和美术仍待试玩调整。
- 队员逐个下令，到位驻守；没有群选、自动跟随或手动技能。道路和敌人入口被占时会等待腾空，请调整队伍让路。
- 没有章节进度、自动存档、失败回退、账号、联网或自动更新。
- 护盾、猎犬、山雀增益、熊山君完整技能及二三星新增技能尚未实现；升星当前主要增加基础属性。
- 灰鼠和唐僧仍使用旧素材；现有动作以关键姿势和程序过渡为主，不是完整逐帧动画。
- 当前有战斗与界面音效，没有完整 BGM、配音或最终混音；英雄退场音效暂未采用。
- Windows 包未进行代码签名，系统可能显示“未知发布者”或 SmartScreen 提示。请核对 SHA-256，不要关闭安全软件。
- 本包由 macOS 使用官方 Godot 4.7.2 Windows x86_64 模板交叉导出；导出结构和资源已检查，但 Windows 实机启动、界面/音效、完整四波、胜败重开与窗口适配仍待验证。
- 仅支持 64 位 Windows。默认窗口为 1440×810；高 DPI、多屏幕、特殊缩放比例和较旧显卡尚未全面测试。

这份限制不会要求试玩者关闭杀毒软件或修改系统安全策略。如果校验值不符，请不要运行并联系发送者。
