# 今晚别偷粮：玩法原型

一个无需安装依赖的浏览器 Demo，用来验证“植物大战僵尸式分路棋盘 + 自走棋三合一升星”。

## 运行

直接双击 `index.html`，或在项目目录启动任意静态文件服务器。

## 当前内容

- 3 条敌人路线、6 列部署格
- 4 种单位：玉米、辣椒、土豆、咖啡
- 商店刷新、购买、备战区、部署、移动和出售
- 3 个同名同星单位合成升星，最高 3 星
- 3 种敌人、8 个波次和完整胜负流程

## 操作

- 点击备战区或棋盘单位，再点击空格进行移动。
- 出现可合成单位时，点击“合成”，再选择要保留的位置。
- 准备完成后点击“开始第 N 波”。

这是机制验证版本，使用临时图形和 Emoji，不代表最终美术。
