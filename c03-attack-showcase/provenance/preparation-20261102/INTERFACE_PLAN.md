## 3. 精确时序与零时长末样本策略

建议首轮采用以下确定性策略，标记为“试接实现选择”，不是来源规定：

1. 默认Ready显示index0，点击播放后从0单次播放。用单一单调时钟，源PTS整数ticks作为边界；`0 <= t < T`按半开区间显示对应源帧，帧率卡顿时按当前时刻定位，不把98项当均匀帧率播放。
2. `t >= T`显式进入Ended，视频时钟停在T，选择index97静态查看。UI提示“播放结束／末帧查看”。这是播放器末态，不给第97项补时长、不把静态查看算进源视频，也不延长到2.985秒。
3. 重播先停止旧声、清理已触发事件和待触发计时，再从0开始，避免声音叠加。退出/重新载入同样清理。
4. 首轮不做自动循环按钮。若以后需要循环，用精确T作为周期，周期覆盖[0,T)；index97仍保留在数据和末态检查中，但不取得正播放区间，不暗中删除或添加尾停顿。需在当轮明确说明这一行为。

这样单次播放能完整保留98条来源记录，并明确观察末态；来源并没有建立额外的末帧停留时长。
