# 熊山君四方向攻击展示

双击 `launch.command` 启动。棋盘上只有一只熊，右上角四个按钮或数字键 `1–4` 分别切换右前、左前、右后、左后；默认右前。选择新方向会从该组动作开头重新播放对应视频原声，先停止旧音，避免叠声。再次选择当前方向不会重新触发。没有战斗、敌人、伤害或游戏菜单，原游戏保持。

## 动作与镜像

- 正面原方向使用已认可的20张去白边修复帧，左前以脚锚为中心水平镜像；源时间、3.5秒视频画面和0.35秒末帧间隔不变。
- 背面原方向使用负责人确认的背面修复视频，右后为原方向、左后为水平镜像。保留340条源时刻和340张PNG（326种不同图像），视频画面3.541667秒，末帧间隔0.35秒，没有套用正面的20帧数量或战斗时长。
- 两组分别读取 `clips.json` 的视频时长、间隔、显示倍率、原始左右方向和音轨；各组manifest提供画布、脚锚及逐帧时间。镜像只改变图像的水平朝向和手持侧，不倒放动作，不改变音频声道。
- 所有方向都围绕同一个棋盘脚点 `(720,441)` 绘制，显示倍率0.75，匹配已确认的棋盘角色尺度。阴影固定于格心；动态脚底是否始终自然贴地仍需结合动作观看。

## 素材来源和限制

正面 `art/attack/` 是 `godot-demo/art/candidates/bear_lord_matte_v2/` 的20张PNG复制件。其动作来自认可的 `forehand-7499-short-windup-v2.mp4`；仅保留20张选帧，原片两帧棍头出画被跳过，因此还有跳帧和首尾切换。局部去白污染已减轻白圈和脚部灰雾，未重绘角色或恢复画外武器；源运动模糊和少量雾感仍保留。旧manifest的820ms、`at` 和 `scale` 字段不参与现在的播放。

背面交接目录为 `godot-demo/art/candidates/bear_lord_back_attack_v1/`。运行目录将该包 `frames/` 的PNG平铺到 `art/back/`，保持manifest中的文件名引用；340张PNG、manifest和WAV均与05最终候选逐字节一致。原视频为负责人确认的 `bear-back-short-repaired-v1.mp4`，图像时间轴按视频轨而非音频尾部定义。画布384×320、脚锚(177,213)；脚边残余灰软边属于源画面覆盖限制，本轮未重绘。

棋盘 `art/forest-board.png` 保持已确认林间版本，SHA-256为 `7b568eb54ad25d18efa7dab24adcce833a4528940fdd615ca053196cd6ad1ed6`；格子144×72。镜像方向和原方向使用同一纹理，不另行生成画面。

原声均按各自视频0秒开始播放，不叠加专门制作的音效。正面 `audio/source-track.wav` 是44.1kHz双声道16位PCM，补79个静音采样保留原音起点偏移，约3.622秒；背面 `audio/back-source-track.wav` 是32kHz双声道16位PCM，115968个采样、3.624秒，从0秒起，不补静音。背面尾部768个AAC填充采样已按视频编辑表移除，未剪掉有效音轨。两段音轨都在各自下一轮开始前结束。视频音轨商用授权未在本展示核实，当前仅供项目内试验；技术同步不代替实际听感。

2026-10-29作者自测：真实源码与排除`.godot`／`.import`／`.uid`的干净副本各2969项、0失败；干净副本专用OpenGL窗口实际采得四向各4张画面，按钮切换成功，棋盘、比例与脚锚一致。正面20张PNG、manifest、原声及棋盘共23个文件与修改前HEAD逐字节一致。独立07验收另行记录，静态采样不代表连续动画或实际听感通过。

图形采样：`./launch.command --rendering-method gl_compatibility --audio-driver Dummy --script res://capture.gd`。默认从四方向各取4个时刻，输出到 `/tmp/bear-four-direction-render/`；追加 `-- --all-frames --output=/tmp/bear-four-direction-all` 可以采集所有源时刻。采集只操作本轮引擎窗口内的控件事件，静音并完成后退出；真实视口静态采样不等同真人连续播放或扬声器试听。

播放器直接读取PNG/WAV，支持没有本机导入缓存的源码启动。若要导出安装包，仍需单独配置并验证原始资源的收录；本轮没有提供安装包。
