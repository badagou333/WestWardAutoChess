# 熊山君普通攻击展示

双击 `launch.command` 启动。独立窗口只显示棋盘和一只熊山君；熊会循环做右前正手攻击，并播放一次攻击声。没有战斗、敌人、伤害或游戏菜单；原游戏不受影响。每张选帧按照源视频相对时间显示，视频画面到 3.500 秒结束后末帧再停留 0.35 秒。攻击声在第 12 张选帧出现时播放（源视频约 1.716667 秒）。

本素材为试验候选，只使用源片中选出的 20 帧，按原时间显示也无法完整还原原视频的连续动作。源片两帧棍头出画已跳过，挥击有跳帧；试验第 10–12 帧有白边和灰脚，原大挥击弧已移除。循环从最后一帧切回首帧，连续衔接尚待完善。棋盘及角色帧均为原样复制；声音取自项目原熊攻击声，其来源与许可见 `audio/ATTRIBUTION.md`。

使用 Godot 4.7 可运行 `./launch.command --headless --script res://test.gd` 做帧序检查；需要图形采样时运行 `./launch.command --rendering-method gl_compatibility --script res://capture.gd`，20 张当前窗口渲染画面写入 `/tmp/bear-showcase-render/`。单帧采样不代替连续播放和实际听感检查。
