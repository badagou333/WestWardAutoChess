# 游戏制作技能清单

更新时间：2026-11-02

本清单记录本项目可使用的游戏制作 Skill、制作环节、来源与维护方式。当前重点是二维人物、棋盘和角色动画。**Skill 是供助手遵循的流程说明，可能附带脚本；它本身不是图像／视频生成模型，也不等于游戏引擎。**

“自制／下载／内置”说明技能来源；“已安装／已使用／已验证”说明使用状态，两者分开记录。技能存在不代表依赖已配置、付费服务已获授权、所有功能已验证或产物已被游戏采用。

## 与即梦和LibTV的分工

本项目可以采用以下流程；每次实际制作仍服从该批任务的授权范围和指定工具。

1. 用 `imagegen` 等实际可用的生图工具制作人物概念图；需要成套游戏素材时使用 `generate2dsprite` 组织制作。
2. 用 `idle-pose-first-frame` 将已选定人物转成符合棋盘镜头的待机首帧，保留身份、持械手与动作留白。
3. 在负责人指定的即梦或LibTV等平台生成动作视频，并选定认可版本。
4. 用 `video2dsprite` 的已有视频流程做解码、透明背景处理、统一画布和脚锚、动作片段整理、导出与检查。
5. 06将交付素材接入Godot；05审核实际画面，07独立验证程序与资源，负责人确认连续观感和听感。

`video2dsprite` 自带调用视频生成服务的部分，但已有视频可以跳过生成步骤。不能因技能支持某个API就擅自改用该服务、重新生成人物或增加费用。它也不能自动修复已经出画的武器、错误肢体、换手或身份变形。

针对本项目，默认先保留认可视频的完整源帧、时间和原声关系；技能附带的示例攻击时长、命中比例、目标高度及循环参数不是游戏已确认数值。确需减帧、改节奏、换色、镜像或重绘时，按当批明确要求处理，详细步骤以 [项目视频转换流程](VIDEO_TO_GAME_WORKFLOW.md) 为准，不在这里复制整套规则。

棋盘与环境使用 `generate2dmap` 的场景流程，最后与人物统一镜头、比例、脚点和格线。`photocraft-retouch` 用于已指定的修图工作；`visualize` 用于讨论和比较方案。

- **Godot、Blender、Spine、PhotoCraft** 是软件；是否有可用操作工具和对应Skill要分别检查。
- **即梦、LibTV** 是视频／媒体制作平台或工作空间；本清单不把平台本身记为自制Skill。
- **05美术、06程序、07测试等聊天** 是项目职责，不是Skill。
- **项目的 [视频转换流程](VIDEO_TO_GAME_WORKFLOW.md)** 是仓库中的自制工作文档，不能当作已经安装的独立Skill或通用一键转换器。
