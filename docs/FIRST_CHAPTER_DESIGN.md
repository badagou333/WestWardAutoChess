# 第一章设计梳理：双叉岭

更新时间：2026-08-28

本文用于整理第一章的剧情、关卡和商店池设计。内容分为“已确认基线”和“待确认提案”；待确认提案只有在项目负责人明确采用后，才能移入 `CONFIRMED_GAME_DESIGN.md`。

## 1. 已确认基线

### 剧情位置

- 第一章暂定从唐僧离开大唐后开始，以唐僧的第一视角经历双叉岭。
- 剧情顺序为：唐僧先在双叉岭遭遇妖怪，之后到达两界山并救出孙悟空。
- 孙悟空可以在第一章结尾的剧情中出场，但不能参加第一章的战斗，也不进入第一章商店池。
- 原著中的唐僧没有亲自击败双叉岭三妖；游戏将这段遭难扩展成护送战斗，属于玩法需要的改编。

### 章节结构

- 第一章共 7 难，每难是一场约 2～4 分钟的战斗。
- 7 难延续同一套章节经济。
- 第 3、5、7 难是 Boss 关，每个 Boss 关由 3 波普通敌人和第 4 波 Boss 组成。
- 第 3、5 难 Boss 被击败后，从下一难开始进入商店。
- 第 7 难 Boss 从下一章开始进入商店。

### Boss 身份与顺序

- 第 3 难 Boss：熊山君，主要战斗方向为范围减速、自我强化和残血恢复。
- 第 5 难 Boss：特处士，主要战斗方向为冲锋和破坏阵型。
- 第 7 难最终 Boss：寅将军，主要战斗方向为高机动并寻找突破口接近唐僧。
- 特处士和寅将军的完整技能与品质仍未确认，三名 Boss 的具体数值和造型仍未确认。
- 熊山君已进一步确认为绿色 2 费英雄并完成技能机制设计；其具体数值和造型仍未确认。

### 初始商店池结构

- 第一章初始商店池共 5 名英雄，全部为白色 1 费英雄。
- 五名英雄的身份和核心定位已经确认：

| 身份 | 类型 | 定位 |
| --- | --- | --- |
| 护寺棍僧 | 凡人 | 防御前排 |
| 山野猎户 | 凡人 | 近战输出 |
| 山雀精 | 友善精怪 | 远程输出 |
| 药灵童子 | 友善精怪 | 治疗辅助 |
| 狐火小妖 | 小妖 | 范围法术 |

- 上述名称目前作为角色身份名使用；正式姓名和造型尚未确认，技能机制已经分别记录在下方。
- 默认结构为一星 1 个简单技能、二星新增第 2 个技能、三星新增第 3 个技能。
- 个别英雄的三星可以不增加独立技能，改为给已有技能增加足以改变玩法的新机制；不能只提高数字。
- 升星同时提升数值并强化外观，数值倍率沿用一星 100%、二星 180%、三星 320% 的暂定规则。
- Demo 中的玉兔、青羽、铁角等角色只是原型占位，不属于第一章正式名单。
- 原计划中的控制辅助“藤蔓小妖”暂不制作，不进入第一章初始商店池；以后是否重新设计和加入另行讨论。

### 已确认技能：护寺棍僧

| 星级 | 新增技能 | 已确认效果 |
| --- | --- | --- |
| 一星 | 横棍护法 | 每次只给一个目标施加护盾，目标可以是自己、一名队友或唐僧；不附带嘲讽和范围护盾 |
| 二星 | 震地棍 | 每隔数次普通攻击，下一击对当前目标及其周围一格敌人造成范围伤害 |
| 三星 | 护经棍阵 | 释放横棍护法时，额外为相邻队友提供较小护盾 |

横棍护法的自动目标优先级，以及各技能的触发次数、伤害倍率、护盾量和持续时间仍未确认，留待可玩版本测试。

### 已确认技能：山野猎户

| 星级 | 新增技能 | 已确认效果 |
| --- | --- | --- |
| 一星 | 猎犬出击 | 战斗开始时召唤一只不占人口的猎犬，优先攻击猎户当前目标 |
| 二星 | 合围 | 猎户和自己的猎犬攻击同一个敌人时，双方造成额外伤害 |
| 三星 | 鹰哨 | 每隔数次普通攻击召来猎鹰，俯冲攻击当前目标后离场 |

猎犬是否占用棋盘格、属性继承比例、死亡后能否重新召唤，以及技能具体数值仍未确认。

### 已确认技能：山雀精

| 星级 | 新增或强化内容 | 已确认效果 |
| --- | --- | --- |
| 一星 | 高枝瞄准 | 身边没有敌人时，提高攻击力和攻击距离 |
| 二星 | 数箭齐发 | 朝一个目标连续射出多支箭，集中攻击该目标 |
| 三星 | 强化数箭齐发 | 不新增独立技能；每支箭穿透首个目标，并继续命中同一方向上的后续敌人 |

箭矢数量、无近身敌人的判定范围、攻击与射程加成、穿透距离和穿透伤害规则仍未确认。

### 已确认技能：药灵童子

| 星级 | 新增技能 | 已确认效果 |
| --- | --- | --- |
| 一星 | 回春露 | 治疗当前生命比例最低的一名友方英雄或唐僧 |
| 二星 | 毒草散 | 投掷毒草药包，造成一次伤害并使目标持续中毒 |
| 三星 | 百草回春 | 同时治疗所有存活的上场英雄和唐僧 |

治疗技能可以恢复唐僧已经损失的生命，关卡星级仍按照战斗结束时的最终生命计算。治疗量、中毒数值、召唤物能否接受治疗及其对评星难度的影响仍未确认。

### 已确认技能：狐火小妖

| 星级 | 新增技能 | 已确认效果 |
| --- | --- | --- |
| 一星 | 狐火团 | 攻击敌人最密集的位置，对小范围内的敌人造成伤害 |
| 二星 | 阴火余烬 | 被狐火团命中的敌人在随后一段时间持续受到灼烧伤害 |
| 三星 | 三尾流火 | 释放狐火团时额外生成两团较弱狐火，攻击附近的其他目标 |

狐火范围、目标选择、灼烧持续时间、额外狐火伤害和各项倍率仍未确认。

### 已确认技能：熊山君

| 星级 | 新增技能 | 已确认效果 |
| --- | --- | --- |
| 一星 | 山君践踏 | 对周围敌人造成范围伤害，并降低其攻击速度和移动速度 |
| 二星 | 暴熊之怒 | 提高攻击力和攻击速度；普通攻击造成范围伤害，并通过造成伤害恢复生命 |
| 三星 | 困兽回生 | 首次进入低生命时解除减速和控制，持续恢复生命，并重置暴熊之怒冷却 |

熊山君确定为绿色 2 费英雄。第 3 难 Boss 形态使用完整的三个技能；击败后从第 4 难开始进入商店，一星招募版本按正常升星顺序解锁技能。具体范围、减速、强化、吸血、触发血线和恢复数值仍未确认。

### 费用池解锁规则

- 费用和品质对应：白色 1 费、绿色 2 费、蓝色 3 费、紫色 4 费、金色 5 费。
- 高费用池必须先通过剧情或 Boss 进度解锁。
- 击败第 3 难熊山君后，第 4 难开始解锁 2 费池。
- 新费用池解锁后，一费等低费英雄仍然保留，方便继续购买和合成。
- 人口只调整已经解锁费用之间的出现概率；尚未解锁的费用概率始终为 0%。
- 在已经解锁的范围内，人口越高，高费英雄出现概率越高。
- 第一章后续 3～5 费池的具体解锁节点尚未确认。

## 2. 第一章叙事节奏

Boss 身份、顺序和主要战斗方向已经确认；其余关卡的叙事、教学作用和正式名称仍是待确认提案。

| 难数 | 剧情与玩法作用 | Boss |
| --- | --- | --- |
| 第 1 难 | 唐僧进入双叉岭；教学招募、布阵和保护中央目标 | 无 |
| 第 2 难 | 山雾加深，敌人从两侧进攻；教学来敌方向预告 | 无 |
| 第 3 难 | 第一次阵容检查，引入范围双速削弱、狂暴输出和残血恢复 | 熊山君（已确认） |
| 第 4 难 | 进入妖岭深处，引入远程或持续伤害敌人 | 无 |
| 第 5 难 | 第二次阵容检查，引入冲锋和破坏阵型的 Boss | 特处士（已确认） |
| 第 6 难 | 虎穴前的混合敌群，综合检验站位、人口和升星 | 无 |
| 第 7 难 | 章节最终战，Boss 会寻找突破口接近唐僧 | 寅将军（已确认） |

章节结束提案：唐僧离开双叉岭，到达两界山，听见山下的孙悟空呼喊“师父”；救出孙悟空后结束第一章。

## 3. 商店池扩展

根据已经确认的 Boss 顺序和解锁规则，刷新池按以下方式成长：

| 生效时间 | 已确认的池内变化 |
| --- | --- |
| 第一章开始 | 5 名白色 1 费英雄 |
| 第 4 难开始 | 解锁绿色 2 费池，并加入绿色 2 费英雄熊山君 |
| 第 6 难开始 | 加入第 5 难 Boss 特处士；其费用仍未确认 |
| 第二章开始 | 加入第 7 难最终 Boss 寅将军；其费用仍未确认 |

熊山君已确定为绿色 2 费英雄。特处士和寅将军的具体品质还未确认。每次解锁新费用池时新增多少名普通英雄也尚未确认，因此暂不计算后续商店池总角色数。

孙悟空是否在第二章免费获得一只、之后再进入商店并参与三合一，仍未确认。

## 4. 需要解决的叙事问题

### 唐僧为什么能在救出孙悟空前组织队伍

原著中唐僧在双叉岭没有自己的战斗队伍。游戏需要为第一章的商店与英雄来源提供一个简洁解释。候选方向包括：

- 唐僧沿途结识临时护卫、猎户、山民和善意精怪。
- 商店不是现实店铺，而是用“缘分”或“愿力”召集同行者的抽象界面。
- 第一章由刘伯钦负责引导护卫队，但不要求他一定成为可购买英雄。

以上解释均未确认。

### 击败的妖怪为什么能被招募

Boss 进入商店的玩法已经确认，但剧情解释还未确认。候选方向包括“收服”“度化”“妖契”或将商店理解为战斗记忆的召唤。

## 5. 下一轮需要确认

1. 初始 5 名英雄的正式姓名和造型。
2. 唐僧在救出孙悟空前，商店与护卫队在剧情中的解释。
3. 孙悟空只在结尾过场亮相，还是第一章开头另加一段大闹天宫序章。
4. 孙悟空在第二章的获取与升星方式。
5. 特处士和寅将军的具体品质，以及 3～5 费池的解锁节点。
6. 熊山君的具体数值和造型，以及特处士、寅将军的完整技能、数值和造型。
7. 藤蔓小妖是否重新设计，以及未来在哪个费用池或章节加入。

## 6. 美术状态

- 当前认可的是一张接近暗色二维手绘动画语言的候选画风探索图。
- 该方向尚未成为最终美术规范，不应据此批量生产正式角色和场景资产。
- 第一章正式英雄名单确定之前，探索图中的兔子枪兵、鸟弓手、鼠妖和虎妖均不能视为已确认角色。
