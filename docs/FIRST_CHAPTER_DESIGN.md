# 第一章设计梳理：双叉岭

更新时间：2026-08-27

本文用于整理第一章的剧情、关卡和商店池设计。内容分为“已确认基线”和“待确认提案”；待确认提案只有在项目负责人明确采用后，才能移入 `CONFIRMED_GAME_DESIGN.md`。

## 1. 已确认基线

### 剧情位置

- 第一章暂定从唐僧离开大唐后开始，以唐僧的第一视角经历双叉岭。
- 剧情顺序为：唐僧先在双叉岭遭遇妖怪，之后到达两界山并救出孙悟空。
- 孙悟空可以在第一章结尾的剧情中出场，但不能参加第一章的战斗，也不进入第一章商店池。
- 原著中的唐僧没有亲自击败双叉岭三妖；游戏将这段遭难扩展成护送战斗，属于玩法需要的改编。

### 章节结构

- 第一章共 7 难，每难是一场约 2～4 分钟的战斗。
- 7 难延续同一套章节经济。
- 第 3、5、7 难是 Boss 关，每个 Boss 关由 3 波普通敌人和第 4 波 Boss 组成。
- 第 3、5 难 Boss 被击败后，从下一难开始进入商店。
- 第 7 难 Boss 从下一章开始进入商店。

### Boss 身份与顺序

- 第 3 难 Boss：熊山君，主要战斗方向为防御和击退。
- 第 5 难 Boss：特处士，主要战斗方向为冲锋和破坏阵型。
- 第 7 难最终 Boss：寅将军，主要战斗方向为高机动并寻找突破口接近唐僧。
- 三名 Boss 的完整技能、品质、数值和造型仍未确认。

### 初始商店池结构

- 第一章初始商店池共 6 名英雄，全部为白色 1 费英雄。
- 六名英雄的身份和核心定位已经确认：

| 身份 | 类型 | 定位 |
| --- | --- | --- |
| 护寺棍僧 | 凡人 | 防御前排 |
| 山野猎户 | 凡人 | 近战输出 |
| 山雀精 | 友善精怪 | 远程输出 |
| 药灵童子 | 友善精怪 | 治疗辅助 |
| 狐火小妖 | 小妖 | 范围法术 |
| 藤蔓小妖 | 小妖 | 控制辅助 |

- 上述名称目前作为角色身份名使用；正式姓名、造型和具体技能内容尚未确认。
- 一星阶段每名英雄只有 1 个简单明确的技能；二星新增第 2 个技能，三星新增第 3 个技能。
- 升星同时提升数值并强化外观，数值倍率沿用一星 100%、二星 180%、三星 320% 的暂定规则。
- Demo 中的玉兔、青羽、铁角等角色只是原型占位，不属于第一章正式名单。

### 费用池解锁规则

- 费用和品质对应：白色 1 费、绿色 2 费、蓝色 3 费、紫色 4 费、金色 5 费。
- 高费用池必须先通过剧情或 Boss 进度解锁。
- 击败第 3 难熊山君后，第 4 难开始解锁 2 费池。
- 新费用池解锁后，一费等低费英雄仍然保留，方便继续购买和合成。
- 人口只调整已经解锁费用之间的出现概率；尚未解锁的费用概率始终为 0%。
- 在已经解锁的范围内，人口越高，高费英雄出现概率越高。
- 第一章后续 3～5 费池的具体解锁节点尚未确认。

## 2. 第一章叙事节奏

Boss 身份、顺序和主要战斗方向已经确认；其余关卡的叙事、教学作用和正式名称仍是待确认提案。

| 难数 | 剧情与玩法作用 | Boss |
| --- | --- | --- |
| 第 1 难 | 唐僧进入双叉岭；教学招募、布阵和保护中央目标 | 无 |
| 第 2 难 | 山雾加深，敌人从两侧进攻；教学来敌方向预告 | 无 |
| 第 3 难 | 第一次阵容检查，引入会阻挡或击退前排的 Boss | 熊山君（已确认） |
| 第 4 难 | 进入妖岭深处，引入远程或持续伤害敌人 | 无 |
| 第 5 难 | 第二次阵容检查，引入冲锋和破坏阵型的 Boss | 特处士（已确认） |
| 第 6 难 | 虎穴前的混合敌群，综合检验站位、人口和升星 | 无 |
| 第 7 难 | 章节最终战，Boss 会寻找突破口接近唐僧 | 寅将军（已确认） |

章节结束提案：唐僧离开双叉岭，到达两界山，听见山下的孙悟空呼喊“师父”；救出孙悟空后结束第一章。

## 3. 商店池扩展

根据已经确认的 Boss 顺序和解锁规则，刷新池按以下方式成长：

| 生效时间 | 已确认的池内变化 |
| --- | --- |
| 第一章开始 | 6 名白色 1 费英雄 |
| 第 4 难开始 | 解锁绿色 2 费池，并加入第 3 难 Boss 熊山君 |
| 第 6 难开始 | 加入第 5 难 Boss 特处士；其费用仍未确认 |
| 第二章开始 | 加入第 7 难最终 Boss 寅将军；其费用仍未确认 |

除熊山君已确定随 2 费池解锁外，特处士和寅将军的具体品质还未确认。每次解锁新费用池时新增多少名普通英雄也尚未确认，因此暂不计算后续商店池总角色数。

孙悟空是否在第二章免费获得一只、之后再进入商店并参与三合一，仍未确认。

## 4. 需要解决的叙事问题

### 唐僧为什么能在救出孙悟空前组织队伍

原著中唐僧在双叉岭没有自己的战斗队伍。游戏需要为第一章的商店与英雄来源提供一个简洁解释。候选方向包括：

- 唐僧沿途结识临时护卫、猎户、山民和善意精怪。
- 商店不是现实店铺，而是用“缘分”或“愿力”召集同行者的抽象界面。
- 第一章由刘伯钦负责引导护卫队，但不要求他一定成为可购买英雄。

以上解释均未确认。

### 击败的妖怪为什么能被招募

Boss 进入商店的玩法已经确认，但剧情解释还未确认。候选方向包括“收服”“度化”“妖契”或将商店理解为战斗记忆的召唤。

## 5. 下一轮需要确认

1. 初始 6 名一费英雄的正式姓名、造型和一至三星技能。
2. 唐僧在救出孙悟空前，商店与护卫队在剧情中的解释。
3. 孙悟空只在结尾过场亮相，还是第一章开头另加一段大闹天宫序章。
4. 孙悟空在第二章的获取与升星方式。
5. 特处士和寅将军的具体品质，以及 3～5 费池的解锁节点。
6. 三名 Boss 的完整技能、数值和造型。

## 6. 美术状态

- 当前认可的是一张接近暗色二维手绘动画语言的候选画风探索图。
- 该方向尚未成为最终美术规范，不应据此批量生产正式角色和场景资产。
- 第一章正式英雄名单确定之前，探索图中的兔子枪兵、鸟弓手、鼠妖和虎妖均不能视为已确认角色。
